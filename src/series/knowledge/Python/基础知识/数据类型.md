## 列表（list）和元组（tuple）的区别？

**锚点**：`可变 vs 不可变：list 增删改，tuple 只读且能当字典键`

1. **可变性**：列表可变，元组不可变
2. **语法**：列表用 `[]`，元组用 `()`
3. **性能**：元组更快、内存占用更小
4. **方法**：列表方法多，元组方法少

使用场景：

1. 列表——需要动态增删改元素
2. 元组——数据不应修改、作为字典的键

## 字典（dict）的实现原理？

**锚点**：`哈希表：平均 O(1)，键必须可哈希，3.7+ 保持插入顺序`

1. 查找、插入、删除平均 O(1) 时间复杂度
2. 键必须是可哈希的（不可变类型）
3. Python 3.7+ 字典保持插入顺序
4. 使用开放寻址法解决哈希冲突
