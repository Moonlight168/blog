## 实例方法、类方法、静态方法的区别？

**锚点**：`实例方法有 self、类方法有 cls、静态方法两者都不要`

1. **实例方法**：需实例调用，可访问实例和类属性
2. **类方法（@classmethod）**：可类调用，只能访问类属性
3. **静态方法（@staticmethod）**：无需 self 或 cls，无特殊访问

```python
class MyClass:
    count = 0

    def instance_method(self):
        return self

    @classmethod
    def get_count(cls):
        return cls.count

    @staticmethod
    def utility(x, y):
        return x + y
```

## 什么是多态？

**锚点**：`不同对象对同一消息做不同响应——Python 靠鸭子类型实现`

```python
class Cat:
    def speak(self):
        return "Meow"

class Dog:
    def speak(self):
        return "Woof"

def make_sound(animal):
    print(animal.speak())

make_sound(Cat())  # Meow
make_sound(Dog())  # Woof
```

## 常用魔法方法有哪些？

**锚点**：`构造 __init__、字符串 __str__/__repr__、容器 __len__/__getitem__/__setitem__、迭代 __iter__/__next__、调用 __call__`

1. `__init__`：构造器
2. `__str__`：str() 调用的字符串表示
3. `__repr__`：repr() 调用的字符串表示
4. `__len__`：len() 调用返回长度
5. `__getitem__` / `__setitem__`：索引访问/赋值
6. `__iter__` / `__next__`：迭代器
7. `__call__`：使对象可调用

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        return f"Vector({self.x}, {self.y})"

    def __len__(self):
        return 2

    def __getitem__(self, index):
        return [self.x, self.y][index]

    def __call__(self):
        return f"Called with ({self.x}, {self.y})"

v = Vector(1, 2)
print(str(v))        # Vector(1, 2)
print(len(v))        # 2
print(v[0])          # 1
print(v())           # Called with (1, 2)
```

## @property 装饰器的作用？

**锚点**：`方法变只读属性访问，可配 getter/setter 做校验`

```python
class Circle:
    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self):
        return self._radius

    @radius.setter
    def radius(self, value):
        if value < 0:
            raise ValueError("半径不能为负")
        self._radius = value

    @property
    def area(self):
        return 3.14 * self._radius ** 2
```
