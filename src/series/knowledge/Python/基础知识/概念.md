## Python 是解释型还是编译型语言？

**锚点**：`解释型，但先编译成字节码再交给 PVM 执行`

1. **执行流程**：源代码 (.py) 编译为字节码 (.pyc) → Python 虚拟机 (PVM) 解释执行字节码
2. **对比**：
   - 解释型：调试容易、速度较慢、跨平台容易
   - 编译型：执行快、需重新编译

## 什么是 GIL（全局解释器锁）？

**锚点**：`CPython 互斥锁：同一时刻只有一个线程执行字节码`

1. **影响**：
   - CPU 密集型任务：无法利用多核，性能受限
   - I/O 密集型任务：影响较小
2. **解决方案**：
   - 使用 `multiprocessing` 多进程
   - 使用 C 扩展释放 GIL

## Python 的内存管理机制？

**锚点**：`引用计数为主 + 垃圾回收处理循环引用 + 内存池减开销`

1. **引用计数（主要）**：每个对象维护引用计数，为 0 时释放
2. **垃圾回收（辅助）**：处理循环引用
3. **内存池管理**：小对象使用内存池减少开销

```python
a = [1, 2, 3]  # 引用计数=1
b = a          # 引用计数=2
del a          # 引用计数=1
del b          # 引用计数=0，释放
```

## 深拷贝与浅拷贝的区别？

**锚点**：`浅拷贝只复制第一层，深拷贝递归复制完全独立`

1. **浅拷贝**：只复制第一层，嵌套对象共享引用
2. **深拷贝**：递归复制所有嵌套对象，完全独立

```python
import copy
original = [1, [2, 3]]
shallow = copy.copy(original)    # 嵌套共享
deep = copy.deepcopy(original)   # 完全独立
```
