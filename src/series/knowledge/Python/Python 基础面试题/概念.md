## Python 是解释型还是编译型语言？

Python 是解释型语言，但实际执行包含编译步骤。

执行流程：

1. 源代码 (.py) 编译为字节码 (.pyc)
2. Python 虚拟机 (PVM) 解释执行字节码

对比：

1. 解释型 - 调试容易，速度较慢，跨平台容易
2. 编译型 - 执行快，需重新编译

## 什么是 GIL（全局解释器锁）？

GIL 是 CPython 解释器中的互斥锁，同一时刻只有一个线程执行 Python 字节码。

影响：

1. CPU 密集型任务 - 无法利用多核，性能受限
2. I/O 密集型任务 - 影响较小

解决方案：

1. 使用 `multiprocessing` 多进程
2. 使用 C 扩展释放 GIL

## Python 的内存管理机制？

1. 引用计数（主要） - 每个对象维护引用计数，为 0 时释放
2. 垃圾回收（辅助） - 处理循环引用
3. 内存池管理 - 小对象使用内存池减少开销

示例：

```python
a = [1, 2, 3]  # 引用计数=1
b = a          # 引用计数=2
del a          # 引用计数=1
del b          # 引用计数=0，释放
```

## 深拷贝与浅拷贝的区别？

1. 浅拷贝 - 只复制第一层，嵌套对象共享引用
2. 深拷贝 - 递归复制所有嵌套对象，完全独立

示例：

```python
import copy
original = [1, [2, 3]]
shallow = copy.copy(original)    # 嵌套共享
deep = copy.deepcopy(original)   # 完全独立
```

## 什么是装饰器？

装饰器是接收函数并返回新函数的工具，在不修改原函数的情况下增加功能。

示例：

```python
def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"耗时：{time.time() - start}")
        return result
    return wrapper

@timer
def my_function():
    time.sleep(1)
```

常见应用：日志记录、性能测试、权限验证、缓存
