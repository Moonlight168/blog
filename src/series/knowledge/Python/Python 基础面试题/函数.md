## Python 函数的定义方式？

基本定义：

```python
def greet(name):
    return f"Hello, {name}"
```

匿名函数（lambda）：

```python
add = lambda x, y: x + y
```

---

## 函数的参数类型有哪些？

1. 位置参数 - 按位置传递
2. 默认参数 - 有默认值，注意必须用不可变类型
3. 可变参数 - `*args` 接收位置参数（元组）
4. 关键字参数 - `**kwargs` 接收关键字参数（字典）
5. 强制关键字参数 - `def func(a, *, b)` 中 b 必须用关键字传递

示例：

```python
def func(a, b=1, *args, **kwargs):
    pass
```

## 什么是闭包（Closure）？

内部函数引用了外部函数的变量。

条件：

1. 嵌套函数
2. 内部函数引用外部函数变量
3. 外部函数返回内部函数

示例：

```python
def make_multiplier(factor):
    def multiplier(x):
        return x * factor
    return multiplier

double = make_multiplier(2)
double(5)  # 10
```

## 装饰器的原理？

装饰器是接收函数并返回新函数的工具。

示例：

```python
def logger(func):
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@logger
def say_hello():
    print("Hello")
```

常见应用：日志记录、性能测试、权限验证、缓存

## 生成器（Generator）是什么？

一种惰性计算的迭代器，使用 yield 关键字。

示例：

```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1

for i in countdown(5):
    print(i)  # 5,4,3,2,1
```

优点：

1. 内存效率高 - 一次只生成一个值
2. 支持无限序列
3. 可组合 - 多个生成器链式调用
