## Python 有哪些内置数据类型？

分为可变和不可变两类。

不可变类型：

1. int - 整数
2. float - 浮点数
3. bool - 布尔值
4. str - 字符串
5. tuple - 元组
6. frozenset - 冻结集合

可变类型：

1. list - 列表
2. dict - 字典
3. set - 集合
4. bytearray - 字节数组

可变类型（list/dict/set）可直接修改对象内容，地址不变；不可变类型修改必新建对象，地址改变

## 列表（list）和元组（tuple）的区别？

1. 可变性 - 列表可变，元组不可变
2. 语法 - 列表用 `[]`，元组用 `()`
3. 性能 - 元组更快，内存占用更小
4. 方法 - 列表方法多，元组方法少

使用场景：

1. 列表 - 需要动态增删改元素
2. 元组 - 数据不应修改、作为字典的键

## 字典（dict）的实现原理？

基于哈希表实现。

特点：

1. 查找、插入、删除平均 O(1) 时间复杂度
2. 键必须是可哈希的（不可变类型）
3. Python 3.7+ 字典保持插入顺序
4. 使用开放寻址法解决哈希冲突

## set 和 dict 的区别？

1. 存储内容 - dict 存键值对，set 只存键
2. 访问方式 - dict 可通过键取值，set 只能判断存在性
3. 用途 - dict 用于映射关系，set 用于去重和集合运算

集合运算：

```python
a = {1, 2, 3}
b = {3, 4, 5}
a | b  # 并集 {1,2,3,4,5}
a & b  # 交集 {3}
a - b  # 差集 {1,2}
```

## 深拷贝与浅拷贝的区别？

1. 浅拷贝 - 只复制第一层，嵌套对象共享引用
2. 深拷贝 - 递归复制所有嵌套对象，完全独立

示例：

```python
import copy
original = [1, [2, 3]]
shallow = copy.copy(original)    # 修改嵌套会影响原对象
deep = copy.deepcopy(original)   # 完全独立
```

## Python 中的 None 表示什么？

`None` 是特殊常量，表示"无"或"空值"。

特点：

1. 单例对象 - 所有 None 都是同一个对象
2. 布尔值为 False
3. 类型为 NoneType

使用场景：

1. 函数默认返回值
2. 默认参数
3. 占位符表示尚未赋值

判断：

```python
if value is None:  # 使用 is，不要用 ==
    print("值为空")
```
