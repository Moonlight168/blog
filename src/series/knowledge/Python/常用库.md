# Python 常用库

## poetry 相比 pip+requirements.txt 有什么优势？

**锚点**：`pyproject 统一管理 + lock 锁版本 + 自动虚拟环境`

1. pyproject.toml 同时管理依赖和项目元数据，统一管理
2. poetry.lock 锁文件保证团队环境一致
3. 无需手动创建和激活虚拟环境
4. 自动处理传递依赖和冲突解析
5. 一条命令发布到 PyPI

## venv 和 conda 的区别？

**锚点**：`venv 轻量只管 Python；conda 全包管理，适合二进制依赖`

1. **venv**：Python 标准库，轻量级，只能隔离 Python 版本
2. **conda**：独立包管理器，支持 Python 和非 Python 包，可隔离不同 Python 版本——适合数据科学和有二进制依赖的项目

## pyproject.toml 有什么用？

**锚点**：`PEP 621 标准：一份文件替代 setup.py/setup.cfg/requirements.txt`

1. 替代 setup.py、setup.cfg、requirements.txt
2. 定义项目元数据、依赖、构建配置
3. PEP 621 是目前推荐的标准格式

## logging 模块怎么配置？

**锚点**：`三选一：dictConfig 最灵活 / fileConfig ini / basicConfig 快速上手`

1. **字典配置（dictConfig）**：灵活，可从文件加载
2. **fileConfig**：ini 格式配置文件
3. **basicConfig**：快速上手

日志级别：`DEBUG < INFO < WARNING < ERROR < CRITICAL`

## pydantic 有什么用？

**锚点**：`基于 TypeHint 的数据验证和设置管理，FastAPI 内置使用`

1. 数据验证和设置管理，基于 TypeHint
2. FastAPI 内置用 pydantic 做请求/响应验证
3. **FastAPI 异常处理器可直接返回 Pydantic 模型**：`ResponseVO(code=400, message=str(exc), data=None)`，FastAPI 自动序列化成 JSON，无需手动 `JSONResponse`

```python
class ResponseVO(BaseModel):
    code: int
    message: str
    data: dict | None = None

@app.exception_handler(ValidationError)
async def validation_exception_handler(request, exc):
    return ResponseVO(code=400, message=str(exc))  # FastAPI 自动序列化
```

## dataclasses 相比普通类有什么优势？

**锚点**：`自动生成样板代码：__init__ / __repr__ / __eq__`

1. 自动生成 `__init__`、`__repr__`、`__eq__`，代码更简洁
2. 支持类型提示
3. 可定义字段默认值和默认值工厂
