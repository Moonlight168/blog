## 怎么验证双重判定锁生效（如何测试）？

**锚点**：`核心验证点：高并发下只有一个线程真正打到数据库`

1. **压测 + 查 DB 请求次数**：手动删缓存 key（模拟失效）→ JMeter 发 1000+ 并发 → 监控数据库查询日志；预期只记录 1 次查询
2. **线程 ID 日志验证**：数据库查询前打线程 ID 日志，压测后应只看到一条
   ```java
   log.info("Thread {} is querying DB", Thread.currentThread().getId());
   ```
3. **CountDownLatch 并发测试**：100 个线程同时释放、同时打热点 key，检查 DB 日志只有 1 次查询
   ```java
   CountDownLatch latch = new CountDownLatch(1);
   ExecutorService pool = Executors.newFixedThreadPool(100);
   for (int i = 0; i < 100; i++) {
       pool.submit(() -> { latch.await(); getData("hotKey"); });
   }
   latch.countDown();  // 所有线程同时执行
   ```
