## Java 有哪些数据类型？

**基本类型（8种）：**
1. 整数：byte（1B）、short（2B）、int（4B）、long（8B）
2. 浮点：float（4B）、double（8B）
3. 字符：char（2B）
4. 布尔：boolean（1B）

**引用类型：** 类、接口、数组、枚举、注解（存储对象的引用地址）

## 数据类型转换方式有哪些？

1. **自动类型转换**：小范围 → 大范围，如 int → long
2. **强制类型转换**：大范围 → 小范围，需手动写 `(类型)`，可能丢数据
3. **字符串转基本类型**：`Integer.parseInt("123")`

**类型转换问题：** 数据丢失、精度损失、类型不匹配

## 为什么用 BigDecimal 不用 double？

double 是二进制浮点数，无法精确表示某些小数（如 0.1），金融计算需用 BigDecimal。

```java
new BigDecimal("0.1")  // 必须用字符串构造
```

## 什么是装箱和拆箱？

1. **装箱**：基本类型 → 包装类，如 `Integer a = 10`
2. **拆箱**：包装类 → 基本类型，如 `int b = a`

**为什么需要？** Java 集合只能存储对象，不能直接存基本类型。

**性能问题：** 循环中频繁装箱会创建大量对象，影响性能。

## Integer 相比 int 的优缺点？

| 项目 | int | Integer |
|------|-----|---------|
| 类型 | 基本类型 | 引用类型 |
| 内存 | 4 字节 | 至少 16 字节 |
| 性能 | 快 | 慢 |
| 空值 | 不支持 | 可以是 null |
| 场景 | 运算密集 | 集合、泛型 |

## Integer 的缓存机制了解吗？

Java 缓存 **-128 ~ 127** 的 Integer 对象，通过 `Integer.valueOf()` 获取该范围的数字时，从缓存取而非新建。

```java
Integer a = 100, b = 100;
a == b;  // true（缓存复用）

Integer c = 200, d = 200;
c == d;  // false（超范围，新建对象）
```
