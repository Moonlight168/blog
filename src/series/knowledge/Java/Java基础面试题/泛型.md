## 什么是泛型？

**锚点**：`类型参数化：定义时用参数，使用时指定具体类型——编译时类型检查`

泛型允许类、接口、方法在定义时使用**类型参数**，使用时再指定具体类型。核心目的是**编译时类型检查**，避免运行时类型转换异常。

## 为什么需要泛型？

**锚点**：`代码复用 + 类型安全`

1. **代码复用**：无需为不同数据类型编写重复代码
2. **类型安全**：编译时约束类型，避免存入错误类型

```java
List<String> list = new ArrayList<>();
list.add("string");
list.add(100);  // 编译报错
```

## 泛型底层是如何实现的？

**锚点**：`类型擦除：编译期替换为 Object，运行时无泛型信息——为兼容 Java 5 之前代码`

Java 的泛型通过**类型擦除**实现：编译器把泛型类型参数替换为上限类型（通常是 Object）。

**后果**：

1. 运行时无法获取泛型类型信息
2. 不能创建泛型数组
3. 基本类型不能作为泛型类型

**为什么这样**：兼容 Java 5 之前的代码。

```java
List<String> list = new ArrayList<>();
// 编译后类型信息被擦除，变成：
List list = new ArrayList();

// 编译器自动补类型转换
String s = list.get(0);  // 编译器补的 cast：(String) list.get(0)
```
