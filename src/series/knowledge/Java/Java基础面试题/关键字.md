## Java 中 final 作用是什么？

1. **修饰类**：该类不能被继承，如 `String` 类
2. **修饰方法**：该方法不能被子类重写
3. **修饰变量**：
   - 基本类型：赋值后不能再修改（常量）
   - 引用类型：引用不能再指向其他对象，但对象内容可修改

## Java 有哪些访问权限修饰符？

1. **public**：任何类都可访问
2. **protected**：同一包内或子类可访问
3. **default**（无修饰符）：同一包内可访问
4. **private**：同一类内可访问

## volatile 保证什么？和 synchronized 的区别？

- **volatile**：保证**可见性**（一个线程修改，其他线程立即可见）、**禁止指令重排**（内存屏障）。**不保证原子性**（i++ 照样错）。
- **synchronized**：保证**原子性 + 可见性 + 有序性**，重量级锁，可修饰方法/代码块。volatile 是轻量级，只解决单变量读写的可见性。
- 区分：volatile 适合状态标志位，synchronized 适合复合操作。
