## Java 中 final 作用是什么？

**锚点**：`类不可继承 / 方法不可重写 / 变量不可再赋值（引用内容可改）`

1. **修饰类**：不能被继承，如 `String`
2. **修饰方法**：不能被子类重写
3. **修饰变量**：基本类型赋值后不可改（常量）；引用类型不能再指向其他对象，但对象内容可修改

## Java 有哪些访问权限修饰符？

**锚点**：`public 全开 / protected 包内+子类 / default 包内 / private 类内`

1. **public**：任何类都可访问
2. **protected**：同一包内或子类可访问
3. **default**（无修饰符）：同一包内可访问
4. **private**：同一类内可访问

## volatile 保证什么？和 synchronized 的区别？

**锚点**：`volatile 保可见性 + 禁重排，不保原子性；synchronized 原子性+可见性+有序性`

- **volatile**：保证**可见性**（一个线程修改其他线程立即可见）、**禁止指令重排**（内存屏障）。**不保证原子性**（i++ 照样错）
- **synchronized**：保证**原子性 + 可见性 + 有序性**，重量级锁，可修饰方法/代码块
- 区分：volatile 轻量，适合状态标志位；synchronized 适合复合操作
