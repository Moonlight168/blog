## 学生类按分数降序、学号升序如何排序？

### 方法1：实现 Comparable
```java
public class Student implements Comparable<Student> {
    private int id;
    private int score;

    @Override
    public int compareTo(Student o) {
        int r = Integer.compare(o.score, this.score); // 分数降序
        return r != 0 ? r : Integer.compare(this.id, o.id); // 学号升序
    }
}
```

### 方法2：Comparator（不改类时使用）
```java
Collections.sort(list, (a, b) -> a.score != b.score
    ? Integer.compare(b.score, a.score)
    : Integer.compare(a.id, b.id));
```

## 秒杀超卖问题如何解决？

### 1. 数据库层面
- **乐观锁**：`UPDATE product SET stock = stock - 1 WHERE id = ? AND stock > 0`
- **悲观锁**：`SELECT ... FOR UPDATE`

### 2. 应用层面
- **Redis 预减库存**：秒杀前加载库存到 Redis，扣减成功再写数据库
- **分布式锁**：Redis/ZooKeeper 确保同一商品只有一个请求处理

### 3. 架构层面
- **限流削峰**：令牌桶、消息队列
- **分层过滤**：前端验证码 → Redis 预减 → 数据库
- **异步处理**：消息队列异步下单

### 4. 业务层面
- **库存预热**：秒杀前加载缓存
- **阶梯释放**：分批次释放库存
- **防重复提交**：token 机制
