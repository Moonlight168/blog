## 什么是反射？

**锚点**：`运行时动态获取类信息、操作对象成员——框架的基石`

1. 获取类的属性、方法、构造器等结构信息
2. 调用任意方法（包括私有方法）
3. 访问/修改任意字段（包括私有字段）

## 反射的应用场景有哪些？

**锚点**：`IOC 容器 / JDBC 驱动加载 / 动态代理 / 序列化框架`

1. **框架 IOC 容器（如 Spring）**：注解扫描 + 反射实现依赖注入——`clazz.getDeclaredConstructor().newInstance()`
2. **加载数据库驱动（JDBC）**：`Class.forName("com.mysql.cj.jdbc.Driver")`
3. **动态代理**：JDK 动态代理通过反射调用目标方法——`method.invoke(target, args)`
4. **序列化框架**：Jackson、FastJson 通过反射获取字段进行序列化/反序列化
