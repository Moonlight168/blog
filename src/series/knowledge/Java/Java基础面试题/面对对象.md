## 怎么理解面向对象？

面向对象将现实事物抽象为**对象**（属性 + 行为），通过对象间交互实现程序功能。

**三大特性：**
1. **封装**：隐藏内部细节，通过接口与外界交互，增强安全性。
2. **继承**：子类共享父类数据和方法，实现代码复用。
3. **多态**：同一接口，不同实例执行不同操作，提升灵活性。

## 多态体现在哪些方面？

1. **方法重载**：同一类中同名方法，参数列表不同（编译时多态）。
2. **方法重写**：子类重定义父类方法（运行时多态，核心）。
3. **接口与实现**：多个类实现同一接口，用接口类型调用方法。
4. **向上/向下转型**：父类引用指向子类对象。

## 多态解决了什么问题？

- **扩展性**：新增子类无需修改现有代码
- **复用性**：通过父类/接口类型统一调用不同子类方法
- **简化代码**：替代冗长的 if-else 判断

## 重载与重写有什么区别？

| 对比维度 | 重载 | 重写 |
|----------|------|------|
| 定义范围 | 同一类中 | 父类与子类之间 |
| 方法签名 | 方法名相同，参数不同 | 方法名、参数、返回类型均一致 |
| 多态类型 | 编译时多态 | 运行时多态 |
| 注解 | 无需 | `@Override` |

## 抽象类和接口有什么区别？

| 对比维度 | 抽象类 | 接口 |
|----------|--------|------|
| 实现方式 | `extends` 继承，仅能继承一个 | `implements` 实现，可实现多个 |
| 方法 | 可包含抽象方法、具体方法 | Java 8+ 支持默认方法、静态方法 |
| 成员变量 | 可有实例变量 | 仅 `public static final` 常量 |
| 构造方法 | 有 | 无 |
| 用途 | 描述共性（状态 + 行为） | 描述能力（行为规范） |

## 抽象类能加 final 修饰吗？

不能。抽象类用于被继承，`final` 禁止继承，语义互斥。

## 抽象类可以被实例化吗？

不能。抽象类包含抽象方法需子类实现，子类实现所有抽象方法后才能实例化。

## 接口可以包含构造函数吗？

不可以。接口不能实例化，构造函数无调用场景。

## 静态变量和静态方法的特点？

**静态变量：**
- 属于类，所有实例共享
- 类加载时初始化，仅一份内存
- 通过"类名.变量名"访问

**静态方法：**
- 无需实例即可调用
- 只能访问静态成员
- 不支持重写，但可被隐藏

## 非静态内部类和静态内部类的区别？

| 对比维度 | 非静态内部类 | 静态内部类 |
|----------|--------------|------------|
| 外部类依赖 | 依赖外部类实例 | 不依赖，可独立实例化 |
| 访问外部成员 | 可访问实例变量和方法 | 仅能访问静态成员 |
| 实例化方式 | `outer.new Inner()` | `new Outer.Inner()` |

## 面向对象设计原则有哪些？

1. **单一职责（SRP）**：一个类只负责一项职责
2. **开放封闭（OCP）**：对扩展开放，对修改封闭
3. **里氏替换（LSP）**：子类可替换父类
4. **接口隔离（ISP）**：接口应小而专
5. **依赖倒置（DIP）**：依赖抽象，不依赖细节
6. **最少知识（LoD）**：一个对象仅与直接关联对象交互

## 单例模式有哪些实现方式？

- **饿汉式** — 类加载时就创建，线程安全，不用也占内存
- **懒汉式** — 第一次调用才创建，基础版线程不安全
- **双重检查锁定（双重检查锁定（Double-Checked Locking，DCL））** — 两次判空 + synchronized + volatile，懒加载 + 高性能，主流写法
- **静态内部类** — 靠 Java 虚拟机（Java Virtual Machine，JVM） 类加载机制保证延迟加载 + 线程安全
- **枚举** — 最简洁，天然防反射和反序列化破环，Effective Java 推荐

> 使用场景：需要全局唯一实例——数据库连接池、配置管理器、线程池等。

## DCL 单例中 volatile 关键字起什么作用？

1. **可见性** — 确保一个线程修改后其他线程立即可见，这是 volatile 的基本语义
2. **禁止指令重排序（DCL 场景核心价值）** — `instance = new Singleton()` 在 JVM 层面分三步：分配内存 → 初始化对象 → 引用指向内存。没有 volatile 时 JVM 可能优化为 分配内存 → 引用指向内存 → 初始化对象，其他线程在第二步后拿到非 null 的半成品对象，调用即出错。volatile 禁止该重排序，保证其他线程看到的要么是 null 要么是完整对象
