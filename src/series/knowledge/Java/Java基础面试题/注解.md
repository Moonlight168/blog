## Java 注解的本质是什么？

**锚点**：`注解 = 接口 + 动态代理对象`

```java
public @interface MyAnnotation {
    String value();
}
// 编译后变成：
public interface MyAnnotation extends Annotation {
    String value();
}
```

JVM 在运行时为注解生成动态代理对象，通过代理获取注解值。

## 注解的作用域如何确定？

**锚点**：`@Target 决定：TYPE / METHOD / FIELD / CONSTRUCTOR / PARAMETER`

常用值：

- **TYPE**：类、接口、枚举
- **METHOD**：方法
- **FIELD**：字段
- **CONSTRUCTOR**：构造器
- **PARAMETER**：方法参数

## 常用注解使用场景有哪些？

**锚点**：`注入 / 声明 Bean / 配置 / AOP / Web / 校验 / 事务 / 序列化 / 自定义`

| 场景 | 注解 |
|------|------|
| 依赖注入 | `@Autowired`、`@Resource` |
| 声明 Bean | `@Component`、`@Service`、`@Repository`、`@Controller` |
| 配置类 | `@Configuration`、`@Bean` |
| AOP 切面 | `@Aspect`、`@Before`、`@Around` |
| Web 接口 | `@RequestMapping`、`@GetMapping`、`@PostMapping`、`@RequestBody` |
| 参数校验 | `@NotNull`、`@NotBlank`、`@Valid` |
| 事务管理 | `@Transactional` |
| 序列化控制 | `@JsonIgnore`、`@JsonProperty` |
| 自定义注解 | `@OperationLog`、`@Idempotent`、`@RequiresPermission` |
