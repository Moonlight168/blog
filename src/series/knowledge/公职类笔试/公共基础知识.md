## 三、政治——三大理论

### 1. 马克思主义哲学

**唯物论**：
- **物质决定意识**，意识是物质的反映，意识对物质有反作用（能动作用）
- **运动是物质的根本属性**，运动和静止是辩证统一的

**辩证法**（三大规律 + 五对范畴）：

| 规律 | 内容 | 例子 |
|------|------|------|
| 对立统一（矛盾） | 矛盾双方相互依存、相互转化 | 福祸相依、安危相易 |
| 量变质变 | 量变引起质变，质变又引起新量变 | 积少成多、水滴石穿 |
| 否定之否定 | 事物发展螺旋式上升、波浪式前进 | 实践-认识-再实践 |

**认识论**：
- 实践是认识的**基础、来源、动力、目的、检验标准**
- 认识具有**反复性、无限性、上升性**

**唯物史观**：
- **社会存在决定社会意识**，社会意识反作用于社会存在
- **人民群众是历史的创造者**
- **社会基本矛盾**：生产力与生产关系、经济基础与上层建筑

### 2. 毛泽东思想

**活的灵魂**：实事求是、群众路线、独立自主。

**主要理论成果**：
- 新民主主义革命理论
- 社会主义改造理论
- 社会主义建设道路探索
- 毛泽东哲学思想（矛盾论、实践论）

### 3. 中国特色社会主义理论体系

| 理论 | 核心 |
|------|------|
| 邓小平理论 | 社会主义初级阶段基本路线、改革开放、"三个有利于" |
| "三个代表"重要思想 | 始终代表中国先进生产力的发展要求、先进文化的前进方向、最广大人民的根本利益 |
| 科学发展观 | 第一要义是发展，核心是以人为本，基本要求是全面协调可持续，根本方法是统筹兼顾 |
| 习近平新时代中国特色社会主义思想 | 十个明确、十四条基本方略 |

**社会主义核心价值观**：富强民主文明和谐（国家）；自由平等公正法治（社会）；爱国敬业诚信友善（个人）

## 四、法律——七部门法高频考点

### 1. 法理学

- **法的渊源**：宪法 > 法律 > 行政法规 > 地方性法规 > 部门规章 > 地方政府规章
- **法的效力等级**：上位法优于下位法、特别法优于一般法、新法优于旧法（**冲突时不同情况不同处理**）
- **法律责任**：民事责任、行政责任、刑事责任、违宪责任

### 2. 宪法

- **国家根本法**，最高法律效力
- **公民基本权利** vs **基本义务**
- **国家机构**：全国人大（最高权力机关）→ 全国人大常委会 → 国家主席 → 国务院 → 地方人大 → 法院/检察院
- **特别行政区**：高度自治，但国防、外交归中央

### 3. 民法典

**核心考点**：
- **民事主体**：自然人、法人、非法人组织
- **民事行为能力**：完全（≥18）、限制（8-18）、无（<8）
- **代理**：法定代理、委托代理
- **诉讼时效**：普通 3 年，最长 20 年
- **物权**：所有权、用益物权、担保物权
- **合同**：要约、承诺、违约责任
- **婚姻家庭**：结婚条件、夫妻共同财产、离婚
- **继承**：法定继承、遗嘱继承、遗赠

### 4. 刑法

**核心考点**：
- **犯罪构成**：四要件（主体、主观、客体、客观）
- **刑事责任年龄**：16/14/12 三档
- **故意犯罪形态**：既遂、未遂、中止、预备
- **共同犯罪**：主犯、从犯、胁从犯、教唆犯
- **刑罚**：主刑（管制、拘役、有期、无期、死刑）+ 附加刑（罚金、剥夺政治权利、没收财产、驱逐出境）

### 5. 行政法

**核心考点**：
- **行政许可**：设定权、程序、撤销、注销
- **行政处罚**：种类、设定权、一事不再罚、听证程序
- **行政强制**：种类（强制执行/即时强制）、程序
- **行政复议**：60 日内申请、复议机关
- **行政诉讼**：受案范围、起诉期限（6 个月）、被告

### 6. 劳动法

- **劳动合同**：试用期（3 年以下合同试用期不超 2 个月；3 年以上不超 6 个月）
- **工作时间**：标准工时 8h/天、44h/周
- **加班费**：平日 150%、周末 200%、法定节假日 300%
- **经济补偿**：N、N+1、2N（违法解除时）

### 7. 公司法

- **公司形式**：有限责任公司、股份有限公司
- **股东权利**：资产收益、参与决策、选择管理者、知情权
- **法人人格否认（揭开公司面纱）**：股东滥用公司法人独立地位和股东有限责任，逃避债务，严重损害公司债权人利益的，应当对公司债务承担连带责任

## 五、公文写作——十四种法定公文

### 法定公文（15 种）

| 文种 | 用途 |
|------|------|
| 命令（令） | 依照有关法律公布行政法规和规章、宣布施行重大强制性措施、批准授予和晋升衔级、嘉奖有关单位和人员 |
| 决定 | 对重要事项作出决策和部署、奖惩有关单位和人员、变更或者撤销下级机关不适当的决定事项 |
| 公告 | 向国内外宣布重要事项或者法定事项 |
| 通告 | 在一定范围内公布应当遵守或者周知的事项 |
| 通知 | 发布、传达要求下级机关执行和有关单位周知或者执行的事项，批转、转发公文 |
| 通报 | 表彰先进、批评错误、传达重要精神和告知重要情况 |
| 议案 | 各級人民政府按照法律程序向同级人民代表大会或者人民代表大会常务委员会提请审议事项 |
| 报告 | 向上级机关汇报工作、反映情况，回复上级机关的询问 |
| 请示 | 向上级机关请求指示、批准 |
| 批复 | 答复下级机关请示事项 |
| 函 | 不相隶属机关之间商洽工作、询问和答复问题、请求批准等 |
| 纪要 | 记载会议主要情况和议定事项 |
| 决议 | 会议讨论通过的重大决策事项（党的机关使用） |

**公文格式要素**（按规范格式）：
```
份号 → 密级和保密期限 → 紧急程度 → 发文机关标志
→ 发文字号 → 签发人 → 红色分隔线 → 标题
→ 主送机关 → 正文 → 附件说明 → 发文机关署名
→ 成文日期 → 印章 → 附注 → 抄送机关
→ 印发机关和印发日期
```

**文种辨析**（高频）：

| 区别 | 关键 |
|------|------|
| 请示 vs 报告 | 请示需要批复、报告不需要；请示一文一事 |
| 通知 vs 通报 | 通知"现在需办"、通报"过去可鉴" |
| 公告 vs 通告 | 公告面向国内外，通告面向一定范围 |
| 函 vs 通知 | 函用于不相隶属机关，通知用于上下级或平级 |
| 决定 vs 命令 | 决定用于重大决策，命令用于法规和强制措施 |

## 六、管理学原理

### 1. 管理的四大职能

**计划 → 组织 → 领导 → 控制**（法约尔）

### 2. 行政决策

- **程序**：发现问题 → 确定目标 → 拟订方案 → 评估方案 → 选择方案 → 实施反馈
- **类型**：程序化决策、非程序化决策
- **方法**：定性决策、定量决策（德尔菲法、头脑风暴法、决策树）

### 3. 行政执行

- **原则**：忠实执行、迅速果断、灵活创新
- **手段**：行政指挥、行政协调、行政控制

### 4. 行政监督

- **内部监督**：上级对下级、专门监督机关（监察、审计）
- **外部监督**：人大监督、司法监督、政协监督、舆论监督、群众监督

### 5. 事业单位管理

- **岗位设置**：管理岗、专业技术岗、工勤技能岗
- **考核**：平时考核、年度考核、聘期考核
- **处分**：警告、记过、降低岗位等级、撤职、开除（**与公务员处分种类基本对应**）

## 七、经济常识

| 概念 | 核心 |
|------|------|
| GDP | 国内生产总值，反映一国（或地区）一定时期内生产活动的最终成果 |
| GNP | 国民生产总值，按国民原则核算 |
| 通货膨胀 | CPI 持续大幅上涨，物价水平普遍上涨 |
| 通货紧缩 | 物价水平持续下降，货币供应量减少 |
| 基尼系数 | 0-1，国际警戒线 0.4 |
| 恩格尔系数 | 食品支出占消费总支出的比重 |
| 财政赤字 | 财政支出 > 财政收入 |
| 货币政策 | 央行的政策（利率、准备金、公开市场操作） |
| 财政政策 | 政府的政策（税收、支出、转移支付） |
| 需求三要素 | 消费、投资、出口（拉动经济的"三驾马车"） |
| 供给侧结构性改革 | 去产能、去库存、去杠杆、降成本、补短板 |

## 九、事业单位改革热点

### 1. 事业单位分类改革

- **公益一类**：完全由政府保障经费（义务教育、公共卫生）
- **公益二类**：部分经费由政府保障（高校、医院）
- **公益三类**：自收自支（已逐步转企改制）

### 2. 事业单位聘用制度

- 签订聘用合同（3-5 年）
- 实行岗位管理（管理岗、专业技术岗、工勤岗）
- 年度考核 + 聘期考核

### 3. 工资制度

- 基本工资 + 绩效工资 + 津贴补贴
- 岗位工资 + 薪级工资 + 绩效

## 十、典型例题精析

### 例 1（哲学）

> "不积跬步，无以至千里；不积小流，无以成江海。"体现的哲学原理是（ ）
>
> A. 质量互变规律  
> B. 对立统一规律  
> C. 否定之否定规律  
> D. 认识发展规律
>
> **答案**：A  
**解析**："跬步"和"千里"、"小流"和"江海"是**量变与质变**的关系，量变积累引起质变。

### 例 2（法律）

> 公务员在法定工作日之外加班的，应当给予补休；不能补休的，应当按照不低于本人日工资的（ ）支付加班费。
>
> A. 100%  B. 150%  C. 200%  D. 300%
>
> **答案**：C  
**解析**：根据《劳动法》第 44 条，周末加班不能补休的按 200% 支付。**注意**：法定节假日是 300%。

### 例 3（公文）

> 下列公文文种中，适用于"不相隶属机关之间商洽工作"的是（ ）
>
> A. 通知  B. 通报  C. 函  D. 请示
>
> **答案**：C  
**解析**："不相隶属机关"是函的核心特征，通知用于上下级或平级、请示用于上下级。

### 例 4（管理）

> 管理的四大基本职能是（ ）
>
> A. 计划、组织、领导、控制  
> B. 决策、计划、组织、控制  
> C. 计划、组织、指挥、协调  
> D. 决策、组织、领导、激励
>
> **答案**：A  
**解析**：经典管理学四职能（法约尔提出）。

### 例 5（时政）

> 2024 年 7 月召开的三中全会审议通过了《中共中央关于进一步全面深化改革、推进中国式现代化的决定》。本次全会的主题是（ ）
>
> A. 全面深化改革  
> B. 中国式现代化  
> C. 进一步全面深化改革、推进中国式现代化  
> D. 全面建成社会主义现代化强国
>
> **答案**：C  
**解析**：2024 年 7 月党的二十届三中全会的主题是"进一步全面深化改革、推进中国式现代化"。

## 十一、30 天复习计划

4. **考前突击**：考前 3 天重点看时政 + 易混淆知识点。
