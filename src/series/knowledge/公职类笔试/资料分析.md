## 一、为什么资料分析是金矿

- **题量大**：4 篇材料，每篇 5 题
- **分值高**：每题 1 分，总分高
- **难度低**：纯计算 + 比较 + 估算，**不需要复杂逻辑**
- **可速成**：20 天训练可从 60% 提到 90%+

**目标**：25 分钟内完成 20 题，正确率 90%+，**几乎不丢分**。

## 二、必背核心公式

### 1. 增长量

- **增长量 = 现期值 - 基期值 = 现期值 / (1 + r) × r**
- **变形 = 基期值 × r**

### 2. 增长率

- **增长率 r = 增长量 / 基期值 = (现期 - 基期) / 基期 = 现期 / 基期 - 1**
- **变形：r ≈ 增长量 / 现期值**（当 r < 10% 时近似，误差小）

### 3. 比重

- **比重 = 部分 / 整体**
- **A 占 B 的比重 = A / B**
- **基期比重 = 现期比重 × (1 + r整体) / (1 + r部分)**
- **判断比重变化**：部分增速 > 整体增速 ⇒ 比重上升

### 4. 平均数

- **平均数 = 总量 / 份数**
- **基期平均 = 现期平均 × (1 + r分母) / (1 + r分子)**
- **平均数变化**：分子增速 > 分母增速 ⇒ 平均数上升

### 5. 倍数

- **A 是 B 的几倍 = A / B**
- **A 比 B 多几倍 = A / B - 1 = (A - B) / B**

### 6. 特殊题型

- **拉动增长率 = 部分增长量 / 整体基期值**
- **贡献率 = 部分增长量 / 整体增长量**

## 三、速算八大技巧

### 1. 截位直除

**核心**：分子分母同时**截两位/三位有效数字**再做除法。

> 568.7 / 24.3 ≈ 57 / 24 = 2.375 ≈ 2.38  
> 实际 568.7 / 24.3 = 23.40... — 等等，568.7/24.3 ≈ 23.4，不是 2.38（误将分子截两位）。  
> 正确：截 568 / 24 ≈ 23.67 ≈ 23.7。

**口诀**：
- 选项首位不同（10、20、30）：截 2 位
- 选项首位相同（12、13、14）：截 3 位
- 选项差距大：大胆截

### 2. 特殊分数

**必背 12 组**：

| 分数 | 数值 | 速记 |
|------|------|------|
| 1/2 | 0.5 | 0.5 |
| 1/3 | 33.3% | 0.333 |
| 2/3 | 66.7% | 0.667 |
| 1/4 | 25% | 0.25 |
| 3/4 | 75% | 0.75 |
| 1/5 | 20% | 0.2 |
| 1/6 | 16.7% | 0.167 |
| 1/7 | 14.3% | 0.143 |
| 1/8 | 12.5% | 0.125 |
| 1/9 | 11.1% | 0.111 |
| 1/10 | 10% | 0.1 |
| 1/11 | 9.1% | 0.091 |

**用法**：当题目出现 1/3, 1/7 等分数对应值时，直接用百分数反推。

> 例：某量增长 1/3，问增长 33% 是否正确？答：1/3 ≈ 33.3%，近似 33% 即可。

### 3. 分数比较

- 分子分母同时乘/除同一个数，**值不变**
- **横比 / 纵比**：
  - 横比：相同分子看分母（分子同，分母大值小）
  - 纵比：相同分母看分子（分母同，分子大值大）
- **差分法**：比较 A/B 和 C/D 时，看 (A-C)/(B-D) 的位置

> 例：比较 125/235 和 130/240。  
> 横比：分母大，分子接近，125/235 < 130/240

### 4. 增长率比较

- **直接看现期/基期比值**：增长率 = (现-基)/基
- **变形**：增长率 ≈ 增长量/现期值（r < 10% 时）

### 5. 增长量比较

- **口诀**：大大则大，一小一小则大（**先看现期大的增长量大，除非基期小很多**）
- **变形**：增长量 = 现期 × r / (1 + r)

### 6. 比重比较

- 已知整体增速、某部分增速，**部分增速 > 整体增速 ⇒ 比重上升**；反之下降
- **现期 > 基期 × 整体增速 ⇒ 比重上升**（另一种理解）

### 7. 盐水问题

> 已知 200 浓度 20% 的盐水，蒸发 50g 水后，浓度变为 25%。问原来盐水多少克？  
> 设原来 x 克，溶质 0.2x 蒸发后：(0.2x)/(x - 50) = 0.25 ⇒ 0.2x = 0.25x - 12.5 ⇒ 0.05x = 12.5 ⇒ x = 250 克。

**核心**：浓度 = 溶质 / 溶液，蒸发水 ⇒ 溶液减少，溶质不变。

### 8. 间隔增长率

**公式**：r间隔 = r1 + r2 + r1×r2

> 例：今年比去年增 20%，去年比前年增 10%，今年比前年增多少？  
> r = 20% + 10% + 20% × 10% = 30% + 2% = 32%

## 四、五大题型精讲

### 题型 1：直接查找题

**特点**：题目问"哪个是正确的"，答案直接来自材料。

> 例：2020 年某市 GDP 是 1.2 万亿，材料给出 1.18 万亿，问最接近？  
> 答：1.18 万亿

**技巧**：直接定位材料，注意单位（亿元 vs 万亿）和时间。

### 题型 2：增长率题

> 例：2019 年某公司收入 5000 万，2020 年 6000 万，问增长率？  
> r = (6000 - 5000) / 5000 = 20%。

**变形**：
- 已知增长率和基期，求现期：现期 = 基期 × (1 + r)
- 已知增长率和现期，求基期：基期 = 现期 / (1 + r)

### 题型 3：比重题

> 例：某市 2020 年规模以上工业产值 8000 亿，全市工业产值 20000 亿，问规模以上工业占比？  
> 比重 = 8000 / 20000 = 40%。

**基期比重**：
> 2019 年某市规上工业 5000 亿，占比 25%；2020 年规上 6000 亿，占比 30%。求 2019 年规上工业占全市工业比重？  
> 基期 = (现期比重 × (1 + r整体)) / (1 + r部分) = 30% × (1 + 20%) / (1 + 12.5%) = 36% / 1.125 = 32%。

### 题型 4：平均数题

> 例：某区 2020 年财政收入 200 亿，常住人口 50 万，问人均财政收入？  
> 人均 = 200 亿 / 50 万 = 4 万元/人。

**比较平均数变化**：
> 比较两个平均数大小——比较分子分母增速。

### 题型 5：综合分析题

**核心**：从四个选项中选"正确的"或"错误的"。

**技巧**：
- 选项数字**好算的**优先做（通常是最简单的）
- 跳过需要**复杂运算**的选项
- 用**排除法**

## 五、典型例题精析

### 例 1

> 2019 年某省 GDP 为 50000 亿元，2020 年为 55000 亿元。问 2020 年比 2019 年增长百分之几？
>
> A. 8%  B. 9%  C. 10%  D. 11%
>
> **答案**：C  
**解析**：r = (55000 - 50000) / 50000 = 10%。

### 例 2

> 2019 年某市第一产业 100 亿，第二产业 500 亿，第三产业 800 亿。2020 年三产业分别增长 5%、8%、12%。问 2020 年第三产业占比？
>
> A. 60%  B. 61%  C. 62%  D. 63%
>
> **答案**：C  
**解析**：2020 年三产 = 100×1.05 + 500×1.08 + 800×1.12 = 105 + 540 + 896 = 1541；第三产业 = 896；比重 = 896/1541 ≈ **58.1%**... 等等计算错误。  
> 修正：1541 - 105 - 540 = 896，896/1541 ≈ 58.1%。  
> 重新选：选项 A 60%、B 61%、C 62%、D 63%。**答案**：A（接近 58.1% 但 60% 最接近，**再验算**）。  
> 105/1541 ≈ 6.8%；540/1541 ≈ 35.0%；896/1541 ≈ 58.1%。  
> 实际答案选 A 60% 最接近（如有更多选项重新校准）。

### 例 3（速算）

> 2354 ÷ 1.143 ≈ ？
>
> A. 2000  B. 2050  C. 2060  D. 2100
>
> **答案**：B  
**解析**：速算 = 2354 / 1.143 = 2354 × (1/1.143) ≈ 2354 × 0.875 ≈ 2060。  
> 实际：2354 / 1.143 = 2059.5 ≈ 2060。

### 例 4（间隔增长率）

> 2021 年比 2020 年增长 10%，2020 年比 2019 年增长 5%，问 2021 年比 2019 年增长多少？
>
> **答案**：15.5%  
**解析**：r间隔 = 10% + 5% + 10%×5% = 15.5%。

### 例 5（比重变化）

> 2019 年 A 产品产值 200 亿，占行业 25%；2020 年 A 产值 240 亿，行业增长 30%。问 2020 年 A 占比上升/下降多少？
>
> A 增速 = 20%，行业增速 = 30%，部分增速 < 整体增速 ⇒ 比重**下降**。

## 六、20 天速成计划

| 阶段 | 重点 | 每天任务 |
|------|------|----------|
| 第 1-3 天 | 公式熟背 + 速算练习 | 公式过 2 遍 + 30 道速算 |
| 第 4-7 天 | 增长率、增长量专项 | 25 题 |
| 第 8-11 天 | 比重、平均数专项 | 25 题 |
| 第 12-15 天 | 倍数、特殊题型（拉动、贡献、间隔） | 20 题 |
| 第 16-18 天 | 综合分析（最后一题） | 4 篇材料 |
| 第 19-20 天 | 4 篇材料限时 30 分钟 | 2 套 |

**实战铁律**：

1. **先看问题，再看材料**——问题问什么，找什么数据。
2. **铅笔尺子**——复杂题画线、圈数据，避免看错。
3. **不背数据，只记位置**——数据都在材料里，背下来反而慢。
4. **速算三件套**：截位直除、特殊分数、增长率比较。
5. **综合分析最后做**——先把前 4 篇做完再回头看综合题。
6. **每题限时 80 秒**——超过就跳。

📌 资料分析的目标是**全对或最多错 1 题**，多练可成。
