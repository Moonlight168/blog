> **适用考试**：公务员申论（国考/省考）、事业单位联考《综合应用能力》（A/B/C/D/E 五类）、国企校招综合测试写作题

## 一、考试形式对比

| 考试 | 卷别 | 时长 | 题量 | 题型 |
|------|------|------|------|------|
| 国考申论 | 副省级 / 地市级 / 行政执法 | 180 分钟 | 5 题 | 概括、对策、综合分析、应用文、文章论述 |
| 省考申论 | 甲类 / 乙类 | 150-180 分钟 | 4-5 题 | 概括、对策、应用文、文章论述 |
| 事业单位联考 A 类 | 综合应用能力 | 120 分钟 | 3-4 题 | 案例分析、文书写作 |
| 事业单位 B 类 | 社会科学专技 | 120 分钟 | 概念分析 + 论证评价 + 综合分析 |
| 事业单位 C 类 | 自然科学专技 | 120 分钟 | 科技文献阅读 + 论证评价 + 材料作文 |
| 事业单位 D 类 | 中小学教师 | 120 分钟 | 辨析 + 案例分析 + 教育方案设计 |
| 事业单位 E 类 | 医疗卫生 | 120 分钟 | 选择 + 实务题 + 案例分析 |

> 注：本文以**通用申论 + 综合应用能力 A 类**为框架，事业单位其他类别重点提示写在末尾。

## 二、申论五大题型

### 题型 1：归纳概括（基础题）

**核心**：把材料中的"答案"原话或近义改写找出来。

**作答公式**：**总括句 + 序号化要点**。

**步骤**：
1. **审题**：明确对象（如"概括做法/原因/问题"）
2. **定位**：在材料中圈出关键词
3. **合并**：同类合并、异类分点
4. **精炼**：每条 30 字以内

> **例题（2019 国考地市级）**：
> 根据材料 1，概括 S 区"融易"工程在乡村治理中的主要做法。（15 分）
>
> **参考答案要点**：
> ① 建设智能化平台，整合数据资源；
> ② 建立村居议事协商机制，引导群众参与；
> ③ 推动政务服务下沉，便民利民；
> ④ 加强矛盾纠纷排查化解。

**注意事项**：
- **点要全**：宁滥勿缺，多答不扣分（少答扣分）
- **条要清**：用"① ② ③"分点，**不要写成一段话**
- **话要准**：原词原句优先，没原文就改写

### 题型 2：提出对策（核心题型）

**核心**：根据材料问题，给出可操作的具体措施。

**作答公式**：**问题 + 对策**（视分值）| **直接对策**（10 分以下）

**对策来源**：
1. **材料直接给出**（抄）
2. **问题反推**（问题→对策）
3. **原因反推**（原因→对策）
4. **经验借鉴**（他人的好做法）

> **例题（2020 国考副省级）**：
> 根据材料 2，分析 N 县基层干部人才流失原因，并提出对策。（20 分）
>
> **参考答案**：
>
> **原因**：
> ① 待遇偏低，晋升渠道窄；
> ② 工作压力大，任务重；
> ③ 培训机会少，能力提升慢。
>
> **对策**：
> ① 完善薪酬和晋升制度，激励基层干部；
> ② 减负增能，关爱基层干部；
> ③ 加强培训，搭建成长平台。

**万能对策词库**：

| 维度 | 常见对策 |
|------|----------|
| 制度 | 完善法规、加强监管、建立机制、落实责任、严格执法 |
| 监管 | 加强执法力度、加大处罚力度、健全信用体系 |
| 资金 | 加大财政投入、引导社会资本、设立专项资金 |
| 技术 | 加大科技投入、推动技术创新、引进先进技术 |
| 人才 | 加强培训、引进高层次人才、完善激励机制 |
| 宣传 | 加强宣传教育、树立先进典型、营造良好氛围 |
| 基层 | 重心下移、资源下沉、加强基层组织建设 |

### 题型 3：综合分析

**三种类型**：

**(1) 解释型**（解释一个词/一句话的含义）

**公式**：
1. 解释（是什么）
2. 分析（为什么/表现）
3. 对策（怎么办）

> **例**：谈谈对"基层治理最后一公里"的理解。
>
> **答**：① 基层治理最后一公里是指政策落实的最终环节，是与群众直接对接的环节。
> ② 当前存在干部能力不足、群众参与度低等问题。
> ③ 应加强基层队伍建设，搭建群众参与平台。

**(2) 评价型**（对观点/现象作出评价）

**公式**：表态 + 分析利弊 + 总结

> **例**：对"网红直播带货"作出评价。
>
> **答**：① 直播带货是新兴的电商模式，**值得肯定**。
> ② 优势：拓宽销售渠道、助农扶贫、拉动消费。
> ③ 不足：虚假宣传、产品质量参差、监管不到位。
> ④ 应加强监管，规范行业秩序。

**(3) 比较型**（对比两种事物）

**公式**：分别论述 + 总结联系

### 题型 4：应用文写作（高频）

**常用文体**：

| 文体 | 格式 |
|------|------|
| 倡议书 | 标题 + 称呼 + 正文（背景、目的、具体倡议） + 落款 |
| 讲话稿 | 标题 + 称呼 + 正文（开场白、主体、结语） + 落款 |
| 报告 | 标题 + 主送 + 正文（情况、问题、措施、展望） + 落款 |
| 通知 | 标题 + 主送 + 正文（缘由、事项、要求） + 落款 |
| 建议书 | 标题 + 主送 + 正文（问题、建议） + 落款 |
| 宣传稿 | 标题 + 正文（背景、内容、号召） |
| 调研报告 | 标题 + 正文（背景、调研方法、发现、建议） |

**格式要求**（公文）：
```
标题（居中）
主送机关（顶格，冒号）
正文（左对齐，每段首行缩进 2 字符）
落款（发文机关 + 日期，右下角）
```

> **例题**：写一份"社区居民文明养犬倡议书"（15 分）
>
> **参考**：
>
> **关于文明养犬的倡议书**
>
> 各位居民朋友：
>
> 随着小区养犬户增多，为维护社区环境，保障居民健康，特发出如下倡议：
>
> 一、依法养犬。及时办理养犬证，定期为犬只接种疫苗。
>
> 二、文明遛犬。遛犬时主动牵绳，及时清理犬只粪便。
>
> 三、爱心养犬。不虐待犬只，不随意遗弃。
>
> 让我们共同营造和谐美好的社区环境！
>
> XX 社区居委会
> 2026 年 7 月 8 日

### 题型 5：文章论述（大作文）

**评分维度**：
- **立意**（20%）：主题鲜明、方向正确
- **结构**（20%）：完整合理、层次清晰
- **论证**（40%）：论据充实、逻辑严密
- **语言**（20%）：规范流畅、富有文采

**常见结构**：

**结构一：五段三分式**（最稳）
```
开头（点题 + 过渡）≈ 150 字
分论点 1 + 论证 ≈ 350 字
分论点 2 + 论证 ≈ 350 字
分论点 3 + 论证 ≈ 350 字
结尾（升华 + 呼应）≈ 150 字
```

**结构二：正反对比式**
```
开头（提出论点）≈ 150 字
正面论述（3 个角度）≈ 500 字
反面论述（3 个角度）≈ 500 字
结尾（总结）≈ 150 字
```

**结构三：层层递进式**
```
是什么 → 为什么 → 怎么办
```

**高分技巧**：

1. **标题亮眼**：对仗式/比喻式/引用式  
   ✓ "让科技创新为高质量发展注入澎湃动能"  
   ✓ "让基层治理更有温度"  
   ✗ "关于基层治理的思考"

2. **开头惊艳**：引言+过渡+论点  
   ✓ "治国安邦，重在基层。基层治理是国家治理的基石，也是服务群众的'最后一公里'。..."  
   ✗ "基层治理很重要，我们要做好基层治理工作。..."

3. **分论点明确**：每段首句是分论点  
   ✓ "以制度创新破解基层治理难题"  
   ✓ "以技术赋能提升基层治理效能"

4. **论据充实**：理论论据（名言、政策）+ 事实论据（材料案例、社会现实）

5. **结尾升华**：  
   ✓ "征程万里风正劲，重任千钧再出发。在新时代的伟大征程上，让基层治理之花处处绽放！"  
   ✗ "我们要努力把基层治理做好。"

**素材积累库**（按主题）：

| 主题 | 素材 |
|------|------|
| 创新 | "创新是引领发展的第一动力"（习近平）；华为研发；大疆无人机 |
| 民生 | "民之所盼，政之所向"；脱贫攻坚；乡村振兴 |
| 文化 | "文化自信是更基本、更深沉、更持久的力量"；敦煌数字化；故宫文创 |
| 基层 | "基础不牢，地动山摇"；枫桥经验；网格化治理 |
| 生态 | "绿水青山就是金山银山"；碳中和；长江禁渔 |

## 三、事业单位综合应用能力（A 类）特殊题型

### 题型 1：案例分析题

**形式**：给一段工作场景，问"如果你是 XX，会怎么做"

**作答框架**：
```
表态（总）
→ 多角度分析（角色、群众、利益、规则）
→ 具体措施（事前 / 事中 / 事后）
→ 总结反思
```

### 题型 2：文书写作（公文类）

**格式**：严格按党政公文格式

**常用公文**：
- **通知**：部署工作、传达事项
- **请示**：请求上级批准
- **报告**：汇报工作、反映情况
- **函**：不相隶属机关商洽工作
- **通报**：表彰先进、批评错误

## 四、四类事业单位专技岗提示

### B 类（社会科学专技）

- **概念分析**：解释一个概念（社会工作、行政管理、心理学）
- **论证评价**：给一段论述，找逻辑错误（偷换概念、论据不足、不当类比等）
- **综合分析**：类似申论，但更专业

### C 类（自然科学专技）

- **科技文献阅读**：阅读科技类材料，回答专业问题
- **论证评价**：与 B 类相似
- **材料作文**：写 800-1000 字议论文

### D 类（中小学教师）

- **辨析题**：判断教育观点正误并分析
- **案例分析**：教育案例分析（学生问题、家校沟通、班级管理）
- **教育方案设计**：设计班会课、活动方案、辅导方案

### E 类（医疗卫生）

- **客观题（医基+临床）**：约 50%
- **案例分析题**：医疗案例分析（约 30%）
- **实务题**：医患沟通、应急处理等（约 20%）

## 五、典型真题精析（2023 国考副省级）

### 题目

> 给定资料 2 中提到"小李的烦恼"。请分析小李遇到的问题，并提出解决建议。（20 分）

### 材料要点

小李是新入职基层公务员，面临：① 工作内容杂；② 与群众沟通难；③ 个人成长慢；④ 心理压力大。

### 参考答案

**问题**：
1. 基层工作繁杂琐碎，缺乏系统培训。
2. 群众诉求多元化，沟通技巧不足。
3. 职业发展路径不清晰，晋升空间有限。
4. 心理压力缺乏疏导渠道。

**建议**：
1. **加强培训**：建立分层分类培训体系，针对基层工作特点开展专项培训。
2. **提升沟通能力**：组织群众工作经验交流，引入案例教学。
3. **完善激励机制**：拓宽基层干部晋升通道，落实职级并行。
4. **健全关爱机制**：建立心理疏导机制，配备专业心理辅导。

**分点要清晰**，**建议要具体可操作**。

## 六、35 天复习计划

| 阶段 | 任务 | 重点 |
|------|------|------|
| 第 1-7 天 | 题型认知 + 范文研读（5 篇/天） | 五大题型基本框架 |
| 第 8-15 天 | 概括题 + 对策题专项练习（每天 1 题） | 找点准确、表达规范 |
| 第 16-23 天 | 综合分析 + 应用文专项（每天 1 题） | 格式 + 逻辑 |
| 第 24-30 天 | 大作文专项（每周 3 篇） | 立意、结构、素材 |
| 第 31-35 天 | 全真模拟（限时限字） | 完整作答 + 字迹工整 |

**实战铁律**：

1. **先看题，再读材料**——带着问题读材料
2. **答题卡格子先画好**——避免格式错误
3. **字迹工整**——这是**隐性加分项**（10-15 分的差距）
4. **时间分配**：概括 8 分钟 / 对策 10 分钟 / 综合分析 15 分钟 / 应用文 25 分钟 / 大作文 50 分钟
5. **大作文一定写完**——写完就有基础分，写不完直接三类文

📌 申论不是语文，是**找点的艺术 + 格式的规范 + 论证的逻辑**。
