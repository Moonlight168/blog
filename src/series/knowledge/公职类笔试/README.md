# 📚 公职类笔试知识库

> 公务员（国考/省考）、事业单位联考、央企/国企校招笔试的通用知识体系。

## 一、适用考试总览

| 考试类型 | 主要科目 | 难度 | 竞争 |
|----------|----------|------|------|
| 国考 | 行测 + 申论 | ★★★★★ | 高 |
| 省考（联考） | 行测 + 申论 | ★★★★ | 高 |
| 事业单位联考 A 类 | 综合应用能力 + 职测 | ★★★★ | 中 |
| 事业单位 B/C/D/E 类 | 综合应用能力（专业） | ★★★★ | 中 |
| 公务员选调生 | 行测 + 申论（部分加试） | ★★★★ | 较高 |
| 银行/电网/烟草/能源/运营商校招 | 行测 + 英语 + 专业知识 | ★★★ | 中 |
| 三支一扶/社区工作者 | 公共基础知识 + 行测 | ★★ | 低 |

> 三大类考试（公务员/事业单位/国企）的公共科目高度重叠，掌握任一即可应对所有。

## 七、心态与方法

**心态**：
- 公职类考试是**长期主义**——失败是常态，坚持就是胜利
- 模拟考 60-70 分不必焦虑，**真题往往更简单**
- 行测**强在取舍**，不要死磕难题
- 申论**重在输出**，必须动手写

**方法**：
- **错题本**是最重要的资料
- **限时训练**是关键（80% 的失败是没练速度）
- **时政突击**是性价比最高的环节
- **字迹工整**是隐性加分项

📌 公职类考试没有天才，只有持续的努力 + 科学的方法。
