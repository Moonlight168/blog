# 非技术面试问答

## JWT token 过期了怎么办？Refresh Token 怎么续期？

- Access Token 短过期（15-30min），Refresh Token 长过期（7-30 天）。
- Access Token 过期 → 客户端拿 Refresh Token 静默换新的 Access Token，用户无感知。
- Refresh Token 也过期才需要重新登录。
- Refresh Token 存服务端（Redis），可主动吊销；Access Token 不存，靠短 TTL 降低泄露风险。
