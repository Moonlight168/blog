## 进程与线程的区别是什么？

| 特性 | 进程 | 线程 |
|------|------|------|
| 资源分配 | 独立内存空间，资源分配单位 | 共享进程资源，CPU调度单位 |
| 切换开销 | 大，需要切换地址空间 | 小，仅需切换CPU状态 |
| 崩溃影响 | 一个进程崩溃不影响其他进程 | 线程崩溃会影响同进程所有线程 |
| 通信方式 | IPC（管道、消息队列等） | 共享内存、锁、条件变量 |
| 创建速度 | 慢，需要分配资源 | 快，复用进程资源 |

## 为什么线程切换比进程切换快？

1. 线程共享进程地址空间，不需要切换页表
2. 进程切换需要刷新 TLB，线程不需要
3. 线程切换只需保存寄存器等少量状态

## 什么是僵尸进程与孤儿进程？

- **僵尸进程**：子进程结束但父进程未调用 wait，占用进程表项
- **孤儿进程**：父进程结束但子进程还在运行，被 init 进程接管
- 僵尸进程过多会耗尽 PID 资源

## 进程间通信（IPC）方式有哪些？

1. **管道**：半双工，父子进程间通信
2. **命名管道**：无亲缘关系进程间通信
3. **消息队列**：内核中的消息链表
4. **共享内存**：最快的 IPC，需要同步机制
5. **信号量**：进程间同步和互斥
6. **信号**：异步事件通知
7. **Socket**：跨机器通信

## 用户态与内核态的区别是什么？

- **用户态**：权限低，禁止访问硬件
- **内核态**：权限高，可执行特权指令
- 切换通过系统调用、中断、异常触发

**为什么要区分？** 保护内核不被应用程序破坏，保证系统安全稳定。

## 什么是系统调用？为什么比函数调用慢？

系统调用是用户态访问内核功能的唯一方式。

**慢的原因：**

1. 需要用户态 → 内核态模式切换
2. 保存/恢复更多上下文
3. 触发陷入（trap）机制

## 什么是临界区？管理要求是什么？

临界区是访问共享资源的程序代码段。

**四个要求：**

1. **互斥**：最多一个进程在临界区
2. **进步**：临界区空时必须让进
3. **有限等待**：等待时间有上界
4. **让权等待**：等待时释放 CPU

## 什么是信号量？P/V操作的作用？

信号量是表示资源数量的非负整数变量。

- **P操作（wait）**：申请资源，s-1，若 s<0 阻塞
- **V操作（signal）**：释放资源，s+1，若 s<=0 唤醒

## 什么是死锁？四个必要条件？

死锁是多个进程互相等待资源，无法继续执行。

**四个必要条件：**

1. **互斥条件**：资源一次只能被一个进程使用
2. **占有并等待**：已获得资源可申请新资源
3. **不可剥夺**：资源不能被抢占
4. **循环等待**：形成循环等待资源关系

## 如何避免死锁？

1. 统一加锁顺序（最常用）
2. tryLock + 超时
3. 减少锁粒度
4. 资源预分配
5. 破坏循环等待条件

## 操作系统调度算法有哪些？

**非抢占式：**

1. **FCFS（先来先服务）**：简单公平，但可能导致短作业长时间等待
2. **SJF（短作业优先）**：平均等待时间最短，但难以预测运行时间

**抢占式：**

1. **时间片轮转（RR）**：适合分时系统，响应性好
2. **优先级调度**：高优先级先执行，需防止饥饿
3. **多级反馈队列**：结合 RR 和优先级，任务运行越长优先级越低

## 什么是上下文切换？

CPU 保存当前任务状态、恢复另一个任务状态的过程。包括寄存器、PC、堆栈等内容。切换过多会降低系统性能。

## 什么是自旋锁？什么时候使用？

拿不到锁时循环等待，不挂起线程。适合锁持有时间非常短的场景，不适合长等待（浪费 CPU）。

## 什么是虚拟内存？有什么用？

为每个进程提供独立、连续的虚拟地址空间。

**作用：**

1. 内存隔离，进程间互不干扰
2. 可运行大于物理内存的程序
3. 安全保护

## 分页和分段的区别？

| 特性 | 分页 | 分段 |
|------|------|------|
| 划分方式 | 固定大小 | 按逻辑划分，大小不定 |
| 碎片 | 无外碎片，有内碎片 | 有外碎片 |
| 地址空间 | 一维 | 二维（段号+段内偏移） |
| 用途 | 内存管理 | 共享和保护 |

## 为什么多级页表能节省内存？

多级页表按需创建，未使用的区域不分配页表，避免为整个虚拟空间分配映射。

## 什么是缺页中断？

访问的虚拟页不在物理内存中，CPU 触发异常，OS 从磁盘加载页面。属于内核态操作，会导致上下文切换。

## 页面置换算法有哪些？

1. **OPT（最佳置换）**：置换未来最长时间不用的页面，理论最优
2. **FIFO（先进先出）**：简单，但可能产生 Belady 现象
3. **LRU（最近最久未使用）**：性能接近 OPT，开销较大
4. **Clock（时钟算法）**：LRU 的近似实现，效率高

## select、poll、epoll 的区别？

| 特性 | select | poll | epoll |
|------|--------|------|-------|
| 连接数限制 | 1024 | 无限制 | 无限制 |
| 工作方式 | 遍历所有 FD | 遍历所有 FD | 事件驱动，只处理变化的 FD |
| 性能 | O(n) | O(n) | O(1) |
| 适用场景 | 连接数少 | 连接数中等 | 高并发，连接数多 |

## 什么是中断？

硬件或软件向 CPU 发出的事件通知，异步发生，CPU 保存当前状态并处理中断。用于 I/O、时钟、系统调用等。

## I/O 控制方式有哪些？

1. **程序控制（轮询）**：CPU 不断查询设备状态
2. **中断驱动**：设备完成后发中断通知 CPU
3. **DMA 方式**：直接内存访问，CPU 只在开始和结束时介入
4. **通道方式**：专门的 I/O 处理器控制

## 磁盘调度算法有哪些？

1. **FCFS**：按请求顺序，公平但效率低
2. **SSTF（最短寻道优先）**：选择最近的请求，可能饥饿
3. **SCAN（电梯算法）**：沿一个方向移动处理请求
4. **C-SCAN**：单向扫描，到达端点后返回起点

## 什么是缓冲区？有什么用？

用于临时存储 I/O 数据。

**作用：**

1. 减少系统调用次数
2. 平滑 I/O 峰值
3. 提高整体吞吐量

## 容器与虚拟机的区别？

| 特性 | 容器 | 虚拟机 |
|------|------|-------|
| 启动速度 | 秒级 | 分钟级 |
| 资源开销 | 小，共享内核 | 大，独立操作系统 |
| 隔离性 | 较弱 | 强 |
| 性能 | 接近原生 | 有损耗 |

## CAS 与互斥锁的区别？

- **CAS**：无锁，compare and swap，循环尝试，适合轻量竞争
- **互斥锁**：有锁，阻塞/挂起线程，适合重量竞争
