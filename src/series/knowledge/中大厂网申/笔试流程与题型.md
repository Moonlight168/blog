## 一、典型笔试流程

### 1. 投递后流程

```
投递简历 → 简历筛选（机筛+HR筛）→ 发起笔试 → 邮件/短信通知
   ↓
   登录 OJ 平台 → 模拟环境测试 → 正式笔试
   ↓
   笔试中：摄像头 + 屏幕录制 + 禁止切屏
   ↓
   提交 → 阅卷（自动判题 + 代码查重）→ 出分
   ↓
   通知面试 / 进入下一轮 / 挂掉
```

### 2. 时间安排

- **笔试时段**：多数公司安排在**工作日晚上 19:00-21:00** 或 **周末 10:00-12:00 / 14:00-16:00 / 19:00-21:00**
- **通知时机**：通常提前 **3-7 天** 邮件/SMS 通知
- **错过/补考**：少数公司提供 1 次补考机会，大部分错过即淘汰

## 二、题型详解

### 题型 1：选择题（计算机基础）

**题量**：10-20 题，**分值占比 30-40%**

**考查范围**：

| 模块 | 占比 | 高频考点 |
|------|------|----------|
| 数据结构 | 20% | 数组、链表、栈队列、树、图、哈希表、堆 |
| 算法 | 20% | 排序、时间复杂度、递归、动态规划 |
| 操作系统 | 15% | 进程线程、死锁、内存管理、虚拟内存、IO |
| 计算机网络 | 15% | TCP/UDP、HTTP、HTTPS、DNS、IP、子网掩码 |
| 数据库 | 15% | SQL 语句、索引、事务、锁、范式 |
| Linux | 10% | 常用命令、文件系统、进程管理 |
| 设计模式 | 5% | 单例、工厂、观察者、装饰器 |

**典型例题**：

> 1. 进程和线程的区别，下列说法错误的是（ ）
>
> A. 进程是资源分配的基本单位  
> B. 线程是 CPU 调度的基本单位  
> C. 同一进程内的线程共享堆内存  
> D. 进程切换的开销小于线程切换
>
> **答案**：D  
**解析**：进程切换需要切换页表、文件句柄、内核栈等，开销远大于线程切换。线程切换只切换线程私有数据（栈、寄存器、程序计数器）。

> 2. HTTP 状态码 404 表示（ ）
>
> A. 服务器内部错误  
> B. 请求未授权  
> C. 资源未找到  
> D. 网关超时
>
> **答案**：C  
**解析**：404 Not Found；500 内部错误；401 未授权；502 网关错误。

> 3. SQL 中，事务的 ACID 特性，C 代表（ ）
>
> A. Consistency 一致性  
> B. Concurrency 并发性  
> C. Cache 缓存  
> D. Cluster 集群
>
> **答案**：A  
**解析**：ACID = Atomicity（原子性）、Consistency（一致性）、Isolation（隔离性）、Durability（持久性）。

### 题型 2：编程题

**题量**：2-4 题，**分值占比 50-60%**

**难度分布**：

| 难度 | 比例 | 说明 |
|------|------|------|
| 简单（Easy） | 30-40% | 10-15 分钟内做完 |
| 中等（Medium） | 40-50% | 20-30 分钟 |
| 困难（Hard） | 10-20% | 30-45 分钟，部分公司允许放弃 |

**评判标准**：

```
得分 = 通过用例数 / 总用例数 × 题目分值

边界情况：
- 内存超限（MLE）：- 0 分
- 运行时错误（RE）：- 0 分
- 超时（TLE）：- 部分分或 0 分
- 答案错误（WA）：- 看用例通过数
- 编译错误（CE）：- 0 分
```

**AC 模式 vs 得分模式**：

- **AC 模式**：通过全部用例得满分，部分通过得部分分或 0 分（牛客常用）
- **得分模式**：按通过用例数给分（赛码、Codeforces 风格）

### 题型 3：简答题（选做）

**题量**：1-2 题

**考查内容**：
- 系统设计：短链系统、秒杀、消息推送
- 场景方案：如何设计千万级 QPS 的网关
- 业务方案：外卖订单状态机、电商促销系统

### 2. 快读模板

**数据量 ≤ 10^5**：用 `Scanner` 或 `BufferedReader`
**数据量 > 10^5**：必须用 `StreamTokenizer` 或自实现快读

```java
// StreamTokenizer 模板
StreamTokenizer in = new StreamTokenizer(new BufferedReader(new InputStreamReader(System.in)));
in.nextToken();
int x = (int) in.nval;  // 读 double 转 int
```

### 3. 高频类库

| 用途 | 类/方法 |
|------|---------|
| 排序 | `Arrays.sort(arr)`、`Arrays.sort(arr, (a,b)->b-a)` |
| 二分 | `Arrays.binarySearch(arr, target)` |
| 哈希表 | `HashMap<K,V>`、`HashSet<T>` |
| 堆 | `PriorityQueue<T>`（默认小根堆，大根堆传 `Comparator.reverseOrder()`） |
| 双端队列 | `ArrayDeque<T>`（比 `LinkedList` 快） |
| 数组转 List | `Arrays.asList(arr)`、`new ArrayList<>(Arrays.asList(arr))` |
| 字符串分割 | `str.split(",")`、`new StringTokenizer(str, ",")` |
| 大数 | `BigInteger`、`BigDecimal` |

### 4. 常用工具方法

```java
// 字符统计
int[] count = new int[26];
for (char c : s.toCharArray()) count[c - 'a']++;

// 字符比较
Character.isLetter(c);
Character.isDigit(c);
Character.toLowerCase(c);

// 数组填充
Arrays.fill(arr, -1);
int[] copy = Arrays.copyOf(arr, arr.length);

// 排序后保留原下标
Integer[] indices = new Integer[n];
for (int i = 0; i < n; i++) indices[i] = i;
Arrays.sort(indices, (a, b) -> Integer.compare(arr[a], arr[b]));
```

### 5. 边界与陷阱

| 陷阱 | 应对 |
|------|------|
| 整数溢出 | 用 `long` 而不是 `int`（如 `int` 最大约 2.1×10^9） |
| 数组越界 | 循环条件 `<=` 还是 `<`，画图确认 |
| 边界 case | 空数组、单元素、全相同元素、最大最小值 |
| 输入换行 | `readLine()` 与 `nextToken()` 混用要先读完 |
| 输出格式 | 行末是否要换行、最后一行换行是否多余 |
| 时空限制 | 时间 O(n log n)、空间 O(n) 是常见要求 |

## 五、典型例题精析

### 例题 1：两数之和（Easy）

**题目**：给定一个整数数组 `nums` 和目标值 `target`，返回和为 `target` 的两个数的下标。

**输入**：
```
4
2 7 11 15
9
```

**输出**：
```
0 1
```

**Java 模板代码**：

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) nums[i] = sc.nextInt();
        int target = sc.nextInt();
        
        // 哈希表 O(n)
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < n; i++) {
            int complement = target - nums[i];
            if (map.containsKey(complement)) {
                System.out.println(map.get(complement) + " " + i);
                return;
            }
            map.put(nums[i], i);
        }
    }
}
```

### 例题 2：最长回文子串（Medium）

**题目**：给定字符串 `s`，找到 `s` 中最长的回文子串。

**输入**：`babad`  
**输出**：`bab` 或 `aba`

**Java 解法（中心扩展）**：

```java
public String longestPalindrome(String s) {
    if (s == null || s.length() < 1) return "";
    int start = 0, end = 0;
    for (int i = 0; i < s.length(); i++) {
        int[] odd = expand(s, i, i);     // 奇数长度中心
        int[] even = expand(s, i, i + 1); // 偶数长度中心
        int[] max = odd[1] - odd[0] > even[1] - even[0] ? odd : even;
        if (max[1] - max[0] > end - start) {
            start = max[0];
            end = max[1];
        }
    }
    return s.substring(start, end + 1);
}

private int[] expand(String s, int left, int right) {
    while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
        left--;
        right++;
    }
    return new int[]{left + 1, right - 1};
}
```

### 例题 3：岛屿数量（Medium）

**题目**：给定 `'1'`（陆地）和 `'0'`（水）的二维网格，计算岛屿数量。

**Java 解法（DFS）**：

```java
public int numIslands(char[][] grid) {
    if (grid == null || grid.length == 0) return 0;
    int count = 0;
    for (int i = 0; i < grid.length; i++) {
        for (int j = 0; j < grid[0].length; j++) {
            if (grid[i][j] == '1') {
                count++;
                dfs(grid, i, j);
            }
        }
    }
    return count;
}

private void dfs(char[][] grid, int i, int j) {
    if (i < 0 || i >= grid.length || j < 0 || j >= grid[0].length || grid[i][j] != '1') return;
    grid[i][j] = '0';  // 标记访问过
    dfs(grid, i + 1, j);
    dfs(grid, i - 1, j);
    dfs(grid, i, j + 1);
    dfs(grid, i, j - 1);
}
```

## 六、笔试实战铁律

### 1. 时间分配

- **选择题**：30-40 秒/题，**不会就蒙**（C 最大但不要全蒙 C）
- **编程题**：
  - Easy 题：**15 分钟** 内完成
  - Medium 题：**20-30 分钟**
  - Hard 题：**30-45 分钟**，超过即放弃

### 2. 答题策略

1. **先看题不写代码**：所有题都过一遍，标记"肯定能做""可能能做""完全不会"
2. **先做拿手的**：保证基础分
3. **难题做部分分**：即使不会最优解，写个暴力也能拿 30-50% 分
4. **看提交结果**：WA 不要慌，先看是 RE 还是 TLE，再针对性优化
5. **不要纠结细节**：在时间允许范围内，写完提交比完美更重要

### 3. 自测与提交

- **必造测试用例**：
  - 空输入（`n=0`、空数组、空字符串）
  - 单元素
  - 全相同元素
  - 最大/最小值
  - 临界值（边界、0、负数）

### 4. 心态管理

- 笔试**不是"做对所有题"**，而是"做对你会的题"
- 一道题 15 分钟没思路 = 放弃，转下一道
- AC 3 道 > 写 4 道但都 WA

### 5. 作弊红线

- **禁止搜索答案**（摄像头监控）
- **禁止切屏**（系统检测切屏次数）
- **禁止使用本地 IDE**（部分公司）
- **禁止多人协作**（视频画面需人脸居中）
- 一旦被判定作弊，**永久拉黑**该公司

## 七、笔试 vs 面试区别

| 维度 | 笔试 | 面试 |
|------|------|------|
| 时间 | 60-120 分钟 | 60-90 分钟 |
| 题量 | 2-4 道编程 + 10-20 选择 | 1-2 道算法 + 项目 + 基础 |
| 评判 | 自动化判题 | 面试官主观评价 |
| 难度 | 偏算法 | 算法 + 基础 + 设计 |
| 沟通 | 无 | 边写边讲思路 |

> **通过了笔试不代表通过面试**——面试会深挖项目、考察系统设计、追问基础八股。

📌 **笔试靠刷题，面试靠积累**——两手都要硬。
