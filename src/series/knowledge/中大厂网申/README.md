## 四、网申流程

### 1. 投递渠道（优先级排序）

1. **内推**：找师兄师姐/校友/同事/牛客/Boss 直聘（**最高效**）
2. **公司官网**：career.byte.com / job.alibaba.com 等
3. **第三方平台**：牛客、脉脉、LinkedIn、Boss 直聘、拉勾
4. **宣讲会/双选会**：线下/线上

### 2. 网申必填项

- **基本信息**：姓名、邮箱、手机、籍贯、政治面貌
- **教育背景**：学校、学历、专业、GPA、排名
- **实习经历**：STAR 法则（Situation-Task-Action-Result）
- **项目经历**：技术栈、难点、个人贡献
- **获奖经历**：国家级 > 省级 > 校级
- **技能证书**：英语四六级、计算机等级、专利/论文
- **自我评价**：1-2 句话突出亮点

### 3. 简历筛选逻辑

**机筛关键词**（HR 系统）：

| 关键词类别 | 例子 |
|------------|------|
| 学校 | 985/211/QS 前 100 |
| 学历 | 本科/硕士/博士 |
| 专业 | 计算机/软工/电子/通信/数学/统计 |
| 技能 | Java/Python/Go/C++、Spring/MySQL/Redis/K8s |
| 实习 | 互联网大厂实习、6 个月以上 |
| 项目 | 完整项目、开源贡献、竞赛获奖 |

**人筛重点**：
- 实习公司的"段位"（BAT/TMD > 二线 > 创业公司）
- 项目深度（**不是列技术栈，而是讲"我解决了什么问题"**）
- GPA 与排名（前 30% 是门槛）
- 竞赛/论文/专利（加分项）

## 五、笔试概况

### 1. 题型分布（典型中大厂）

| 题型 | 题量 | 时长 | 难度 | 说明 |
|------|------|------|------|------|
| 选择题（计算机基础）| 10-20 | 30 分钟 | 中 | 数据结构、操作系统、网络、数据库、Linux 命令 |
| 编程题 | 2-4 | 60-90 分钟 | 难 | LeetCode 简单-中等为主，有 1 道 Hard |
| 简答题（选做）| 1-2 | 30 分钟 | - | 系统设计、场景方案 |

### 2. 难度分级

| 公司 | 难度 | 备注 |
|------|------|------|
| 字节跳动 | ★★★★★ | 编程题难度最高，4 道题常有 Hard |
| 阿里巴巴 | ★★★★ | 偏系统设计，Java 生态多 |
| 腾讯 | ★★★★ | 算法+系统设计并重 |
| 美团 | ★★★★ | 业务导向，工程题多 |
| 京东/拼多多 | ★★★ | 偏中等，数据库题多 |
| 滴滴/快手 | ★★★★ | 算法题偏 Hard |
| 小红书/知乎 | ★★★ | 难度略低 |
| 华为 | ★★★ | 通信/操作系统题多 |
| 银行科技部 | ★★ | 偏基础知识，编程题简单 |

### 3. 在线评测（OJ）平台

- **牛客网**：字节、美团、京东、快手等
- **赛码网**：阿里、腾讯、华为等
- **HackerRank**：外企、Google、Meta
- **LeetCode**：北美公司、外企
- **Codeforces**：俄罗斯公司、Vivo、虎牙等

### 4. 注意事项

- **摄像头监控**：人脸识别 + 屏幕录制
- **禁止切屏**：大部分公司要求锁定浏览器
- **禁止本地 IDE**：只能用平台内置编辑器（部分允许 VSCode 插件版）
- **题目保密**：题目一般签 NDA，考完不能外传
- **作弊检测**：代码查重 + 行为分析

## 六、刷题路径（30 天速成）

| 阶段 | 时长 | 重点 |
|------|------|------|
| 第 1-5 天 | 数据结构基础 | 数组、链表、栈、队列、哈希表 |
| 第 6-10 天 | 基础算法 | 排序、二分、双指针、滑动窗口 |
| 第 11-15 天 | 进阶结构 | 二叉树、图、堆、Trie |
| 第 16-20 天 | 核心算法 | DFS/BFS、回溯、贪心 |
| 第 21-25 天 | 动态规划 | 入门、线性 DP、区间 DP、背包 |
| 第 26-30 天 | 综合套题 | 模拟笔试（每天 1 套 2-3 题） |

**核心提示**：
- **每天 3-5 题**，**重复刷 > 一次性刷**——同一道题 3 天后再做 1 遍才真正会
- **分类刷 > 随机刷**——按题型归类，总结套路
- **看题解 > 硬憋**——超过 20 分钟没思路就放弃
- **写测试用例**——做完一定要造边界 case
- **Java 刷题常用**：`Arrays.sort`、`HashMap`、`PriorityQueue`、`Deque`
