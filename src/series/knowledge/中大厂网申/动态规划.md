> 动态规划（Dynamic Programming, DP）是**算法面试/笔试中最难、最重要**的题型。占比 30%+，常以 Hard 出现。本篇覆盖 7 大类 DP 题型 + 30+ 经典例题。

## 一、DP 核心思想

### 1. 三大要素

| 要素 | 说明 | 例子 |
|------|------|------|
| **状态定义** | `dp[i]` 或 `dp[i][j]` 代表什么 | `dp[i]` = 爬到第 i 阶的方法数 |
| **状态转移方程** | `dp[i]` 如何由前面的状态推出 | `dp[i] = dp[i-1] + dp[i-2]` |
| **初始条件 + 边界** | `dp[0]`、`dp[1]` 等 | `dp[0] = 1, dp[1] = 1` |

### 2. 两种实现

**自顶向下（递归 + 记忆化）**：

```java
int[] memo;

public int solve(int n) {
    if (n <= 1) return 1;
    if (memo[n] != 0) return memo[n];
    return memo[n] = solve(n - 1) + solve(n - 2);
}
```

**自底向上（递推）**：

```java
public int solve(int n) {
    if (n <= 1) return 1;
    int[] dp = new int[n + 1];
    dp[0] = dp[1] = 1;
    for (int i = 2; i <= n; i++) dp[i] = dp[i - 1] + dp[i - 2];
    return dp[n];
}
```

### 3. DP 适用场景

- **最优子结构**：问题的最优解包含子问题的最优解
- **重叠子问题**：递归时会重复计算相同子问题
- **无后效性**：当前状态确定后，后续决策与之前无关

## 二、线性 DP（入门）

### 1. 爬楼梯（LeetCode 70）— Easy

**题目**：每次爬 1 或 2 阶，爬到 n 阶有几种方法。

**状态**：`dp[i]` = 爬到第 i 阶的方法数
**转移**：`dp[i] = dp[i-1] + dp[i-2]`
**初始**：`dp[1] = 1, dp[2] = 2`

```java
public int climbStairs(int n) {
    if (n <= 2) return n;
    int[] dp = new int[n + 1];
    dp[1] = 1; dp[2] = 2;
    for (int i = 3; i <= n; i++) dp[i] = dp[i-1] + dp[i-2];
    return dp[n];
}

// 空间优化
public int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;
    for (int i = 3; i <= n; i++) {
        int c = a + b;
        a = b;
        b = c;
    }
    return b;
}
```

### 2. 打家劫舍（LeetCode 198）

**状态**：`dp[i]` = 偷到第 i 家能获得的最大金额
**转移**：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

```java
public int rob(int[] nums) {
    if (nums.length == 0) return 0;
    if (nums.length == 1) return nums[0];
    int prev2 = 0, prev1 = 0;
    for (int num : nums) {
        int cur = Math.max(prev1, prev2 + num);
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```

### 3. 打家劫舍 II（LeetCode 213）— 环形

**核心**：拆成两个子问题
- 偷 [0, n-1]（不含最后一间）
- 偷 [1, n]（不含第一间）

```java
public int rob(int[] nums) {
    if (nums.length == 1) return nums[0];
    return Math.max(robRange(nums, 0, nums.length - 1),
                    robRange(nums, 1, nums.length));
}

private int robRange(int[] nums, int start, int end) {
    int prev2 = 0, prev1 = 0;
    for (int i = start; i < end; i++) {
        int cur = Math.max(prev1, prev2 + nums[i]);
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```

### 4. 最长递增子序列（LeetCode 300）— 经典

**O(n²) 解法**：

```java
public int lengthOfLIS(int[] nums) {
    int n = nums.length;
    int[] dp = new int[n];
    Arrays.fill(dp, 1);
    int res = 1;
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                dp[i] = Math.max(dp[i], dp[j] + 1);
            }
        }
        res = Math.max(res, dp[i]);
    }
    return res;
}
```

**O(n log n) 解法（二分 + 贪心）**：

```java
public int lengthOfLIS(int[] nums) {
    List<Integer> tails = new ArrayList<>();
    for (int num : nums) {
        int idx = binarySearch(tails, num);
        if (idx == tails.size()) tails.add(num);
        else tails.set(idx, num);
    }
    return tails.size();
}

private int binarySearch(List<Integer> tails, int target) {
    int left = 0, right = tails.size();
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (tails.get(mid) < target) left = mid + 1;
        else right = mid;
    }
    return left;
}
```

### 5. 最小花费爬楼梯（LeetCode 746）

public int minCostClimbingStairs(int[] cost) {

### 6. 解码方法（LeetCode 91）

**状态**：`dp[i]` = 前 i 个字符的解码方法数
**转移**：
- `s[i-1] != '0'`：`dp[i] += dp[i-1]`
- `s[i-2..i-1]` 是 10-26：`dp[i] += dp[i-2]`

```java
public int numDecodings(String s) {
    int n = s.length();
    int[] dp = new int[n + 1];
    dp[0] = 1;
    for (int i = 1; i <= n; i++) {
        if (s.charAt(i - 1) != '0') dp[i] += dp[i - 1];
        if (i >= 2) {
            int two = Integer.parseInt(s.substring(i - 2, i));
            if (two >= 10 && two <= 26) dp[i] += dp[i - 2];
        }
    }
    return dp[n];
}
```

## 三、背包问题

### 1. 0/1 背包

**状态**：`dp[i][j]` = 前 i 个物品中选，容量为 j 的最大价值
**转移**：
- 不选 i：`dp[i][j] = dp[i-1][j]`
- 选 i：`dp[i][j] = dp[i-1][j-weight[i]] + value[i]`

**模板**：

```java
int[] dp = new int[capacity + 1];
for (int i = 0; i < n; i++) {
    for (int j = capacity; j >= weight[i]; j--) {  // 倒序！
        dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
    }
}
```

**注意**：`j` 必须**倒序遍历**，否则会重复选取。

#### 例题：分割等和子集（LeetCode 416）

**转换**：能否从数组中选出一些数，使和 = 总和 / 2 = 0/1 背包问题

```java
public boolean canPartition(int[] nums) {
    int sum = 0;
    for (int num : nums) sum += num;
    if (sum % 2 != 0) return false;
    int target = sum / 2;
    boolean[] dp = new boolean[target + 1];
    dp[0] = true;
    for (int num : nums) {
        for (int j = target; j >= num; j--) {
            dp[j] = dp[j] || dp[j - num];
        }
    }
    return dp[target];
}
```

#### 例题：目标和（LeetCode 494）

**转换**：设正数和为 P，负数绝对值和为 N，则 P - N = target，P + N = sum。P = (sum + target) / 2

```java
public int findTargetSumWays(int[] nums, int target) {
    int sum = 0;
    for (int num : nums) sum += num;
    if (Math.abs(target) > sum || (sum + target) % 2 != 0) return 0;
    int p = (sum + target) / 2;
    int[] dp = new int[p + 1];
    dp[0] = 1;
    for (int num : nums) {
        for (int j = p; j >= num; j--) {
            dp[j] += dp[j - num];
        }
    }
    return dp[p];
}
```

#### 例题：最后一块石头的重量 II（LeetCode 1049）

**转换**：将石头分成两堆，差值最小 = 0/1 背包

```java
public int lastStoneWeightII(int[] stones) {
    int sum = 0;
    for (int s : stones) sum += s;
    int target = sum / 2;
    int[] dp = new int[target + 1];
    for (int s : stones) {
        for (int j = target; j >= s; j--) {
            dp[j] = Math.max(dp[j], dp[j - s] + s);
        }
    }
    return sum - 2 * dp[target];
}
```

### 2. 完全背包

**区别**：每种物品可以**取无限次**。
**关键**：`j` 必须**正序遍历**。

#### 例题：零钱兑换（LeetCode 322）

**状态**：`dp[i]` = 凑出金额 i 的最少硬币数
**转移**：`dp[i] = min(dp[i], dp[i - coin] + 1)`

```java
public int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1);
    dp[0] = 0;
    for (int i = 1; i <= amount; i++) {
        for (int coin : coins) {
            if (coin <= i) {
                dp[i] = Math.min(dp[i], dp[i - coin] + 1);
            }
        }
    }
    return dp[amount] == amount + 1 ? -1 : dp[amount];
}
```

#### 例题：零钱兑换 II（LeetCode 518）— 组合数

**状态**：`dp[i]` = 凑出金额 i 的组合数
**转移**：`dp[i] += dp[i - coin]`

```java
public int change(int amount, int[] coins) {
    int[] dp = new int[amount + 1];
    dp[0] = 1;
    for (int coin : coins) {
        for (int j = coin; j <= amount; j++) {  // 正序
            dp[j] += dp[j - coin];
        }
    }
    return dp[amount];
}
```

#### 例题：完全平方数（LeetCode 279）

```java
public int numSquares(int n) {
    int[] dp = new int[n + 1];
    Arrays.fill(dp, n + 1);
    dp[0] = 0;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j * j <= i; j++) {
            dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
        }
    }
    return dp[n];
}
```

### 3. 二维背包

#### 例题：一和零（LeetCode 474）

**状态**：`dp[i][j]` = 最多用 i 个 0、j 个 1 能选出的最多字符串数

```java
public int findMaxForm(String[] strs, int m, int n) {
    int[][] dp = new int[m + 1][n + 1];
    for (String s : strs) {
        int[] count = countZerosOnes(s);
        for (int i = m; i >= count[0]; i--) {
            for (int j = n; j >= count[1]; j--) {
                dp[i][j] = Math.max(dp[i][j], dp[i - count[0]][j - count[1]] + 1);
            }
        }
    }
    return dp[m][n];
}

private int[] countZerosOnes(String s) {
    int[] count = new int[2];
    for (char c : s.toCharArray()) count[c - '0']++;
    return count;
}
```

## 四、区间 DP

### 1. 最长回文子序列（LeetCode 516）

**状态**：`dp[i][j]` = s[i..j] 的最长回文子序列长度
**转移**：
- `s[i] == s[j]`：`dp[i][j] = dp[i+1][j-1] + 2`
- 否则：`dp[i][j] = max(dp[i+1][j], dp[i][j-1])`

```java
public int longestPalindromeSubseq(String s) {
    int n = s.length();
    int[][] dp = new int[n][n];
    for (int i = 0; i < n; i++) dp[i][i] = 1;
    for (int i = n - 1; i >= 0; i--) {
        for (int j = i + 1; j < n; j++) {
            if (s.charAt(i) == s.charAt(j)) {
                dp[i][j] = (j - i == 1) ? 2 : dp[i + 1][j - 1] + 2;
            } else {
                dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[0][n - 1];
}
```

### 2. 戳气球（LeetCode 312）— Hard

**状态**：`dp[i][j]` = 戳破 (i, j) 之间所有气球（不含 i、j）能获得的最大硬币数
**转移**：枚举 k 在 (i, j) 中间最后被戳：`dp[i][j] = max(dp[i][k] + dp[k][j] + nums[i]*nums[k]*nums[j])`

```java
public int maxCoins(int[] nums) {
    int n = nums.length;
    int[] a = new int[n + 2];
    a[0] = a[n + 1] = 1;
    System.arraycopy(nums, 0, a, 1, n);
    
    int[][] dp = new int[n + 2][n + 2];
    for (int i = n - 1; i >= 0; i--) {
        for (int j = i + 2; j <= n + 1; j++) {
            for (int k = i + 1; k < j; k++) {
                dp[i][j] = Math.max(dp[i][j], dp[i][k] + dp[k][j] + a[i] * a[k] * a[j]);
            }
        }
    }
    return dp[0][n + 1];
}
```

## 五、字符串 DP

### 1. 最长公共子序列（LeetCode 1143）

**状态**：`dp[i][j]` = text1[0..i-1] 和 text2[0..j-1] 的 LCS 长度
**转移**：
- `text1[i-1] == text2[j-1]`：`dp[i][j] = dp[i-1][j-1] + 1`
- 否则：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

```java
public int longestCommonSubsequence(String text1, String text2) {
    int m = text1.length(), n = text2.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[m][n];
}
```

### 2. 编辑距离（LeetCode 72）— Hard

**状态**：`dp[i][j]` = word1[0..i-1] 转换成 word2[0..j-1] 的最少操作数
**转移**：
- `word1[i-1] == word2[j-1]`：`dp[i][j] = dp[i-1][j-1]`
- 否则：`dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1`（删/插/替）

```java
public int minDistance(String word1, String word2) {
    int m = word1.length(), n = word2.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 0; i <= m; i++) dp[i][0] = i;
    for (int j = 0; j <= n; j++) dp[0][j] = j;
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1];
            } else {
                dp[i][j] = Math.min(Math.min(dp[i - 1][j], dp[i][j - 1]), dp[i - 1][j - 1]) + 1;
            }
        }
    }
    return dp[m][n];
}
```

### 3. 不同子序列（LeetCode 115）— Hard

**状态**：`dp[i][j]` = s[0..i-1] 中 t[0..j-1] 出现的次数
**转移**：
- `s[i-1] == t[j-1]`：`dp[i][j] = dp[i-1][j-1] + dp[i-1][j]`
- 否则：`dp[i][j] = dp[i-1][j]`

```java
public int numDistinct(String s, String t) {
    int m = s.length(), n = t.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 0; i <= m; i++) dp[i][0] = 1;
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s.charAt(i - 1) == t.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j];
            } else {
                dp[i][j] = dp[i - 1][j];
            }
        }
    }
    return dp[m][n];
}
```

### 4. 正则表达式匹配（LeetCode 10）— Hard

```java
public boolean isMatch(String s, String p) {
    int m = s.length(), n = p.length();
    boolean[][] dp = new boolean[m + 1][n + 1];
    dp[0][0] = true;
    for (int j = 2; j <= n; j += 2) {
        if (p.charAt(j - 1) == '*') dp[0][j] = dp[0][j - 2];
    }
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (p.charAt(j - 1) == '*') {
                dp[i][j] = dp[i][j - 2] ||
                           (dp[i - 1][j] && (p.charAt(j - 2) == s.charAt(i - 1) || p.charAt(j - 2) == '.'));
            } else {
                dp[i][j] = dp[i - 1][j - 1] && (p.charAt(j - 1) == s.charAt(i - 1) || p.charAt(j - 1) == '.');
            }
        }
    }
    return dp[m][n];
}
```

## 六、状态机 DP

### 买卖股票系列

**通用框架**：

```
dp[i][k][0/1] = 第 i 天最多 k 次交易，0/1 表示是否持有股票的最大利润
```

#### LeetCode 188：买卖股票的最佳时机 IV — Hard

```java
public int maxProfit(int k, int[] prices) {
    int n = prices.length;
    if (n == 0) return 0;
    k = Math.min(k, n / 2);
    int[][][] dp = new int[n][k + 1][2];
    for (int i = 0; i < n; i++) {
        for (int j = 1; j <= k; j++) {
            if (i == 0) {
                dp[i][j][0] = 0;
                dp[i][j][1] = -prices[i];
                continue;
            }
            dp[i][j][0] = Math.max(dp[i - 1][j][0], dp[i - 1][j][1] + prices[i]);
            dp[i][j][1] = Math.max(dp[i - 1][j][1], dp[i - 1][j - 1][0] - prices[i]);
        }
    }
    return dp[n - 1][k][0];
}
```

#### LeetCode 309：含冷冻期

```java
public int maxProfit(int[] prices) {
    int n = prices.length;
    if (n == 0) return 0;
    int[][] dp = new int[n][2];
    dp[0][0] = 0;
    dp[0][1] = -prices[0];
    for (int i = 1; i < n; i++) {
        dp[i][0] = Math.max(dp[i - 1][0], dp[i - 1][1] + prices[i]);
        dp[i][1] = Math.max(dp[i - 1][1], (i >= 2 ? dp[i - 2][0] : 0) - prices[i]);
    }
    return dp[n - 1][0];
}
```

## 七、树形 DP

### 打家劫舍 III（LeetCode 337）

**状态**：每个节点返回 `[不偷, 偷]` 两种状态下的最大金额

```java
public int rob(TreeNode root) {
    int[] res = dfs(root);
    return Math.max(res[0], res[1]);
}

private int[] dfs(TreeNode node) {
    if (node == null) return new int[]{0, 0};
    int[] left = dfs(node.left);
    int[] right = dfs(node.right);
    int rob = node.val + left[0] + right[0];
    int notRob = Math.max(left[0], left[1]) + Math.max(right[0], right[1]);
    return new int[]{notRob, rob};
}
```

## 八、网格 DP

### 1. 不同路径（LeetCode 62）

```java
public int uniquePaths(int m, int n) {
    int[][] dp = new int[m][n];
    for (int i = 0; i < m; i++) dp[i][0] = 1;
    for (int j = 0; j < n; j++) dp[0][j] = 1;
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
        }
    }
    return dp[m - 1][n - 1];
}
```

### 2. 最小路径和（LeetCode 64）

```java
public int minPathSum(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[][] dp = new int[m][n];
    dp[0][0] = grid[0][0];
    for (int i = 1; i < m; i++) dp[i][0] = dp[i - 1][0] + grid[i][0];
    for (int j = 1; j < n; j++) dp[0][j] = dp[0][j - 1] + grid[0][j];
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[i][j] = Math.min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j];
    }
    return dp[m - 1][n - 1];
}
```

### 3. 最大正方形（LeetCode 221）

```java
public int maximalSquare(char[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    int[][] dp = new int[m + 1][n + 1];
    int res = 0;
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (matrix[i - 1][j - 1] == '1') {
                dp[i][j] = Math.min(Math.min(dp[i - 1][j], dp[i][j - 1]), dp[i - 1][j - 1]) + 1;
                res = Math.max(res, dp[i][j]);
            }
        }
    }
    return res * res;
}
```

## 九、概率/数学 DP

### 1. 骑士拨号器（LeetCode 935）— Hard

**状态**：`dp[i][j]` = 跳到第 i 步落在数字 j 的方案数

```java
public int knightDialer(int n) {
    int MOD = 1_000_000_007;
    int[][] moves = {
        {4, 6}, {6, 8}, {7, 9}, {4, 8}, {0, 3, 9}, {},
        {0, 1, 7}, {2, 6}, {1, 3}, {2, 4}
    };
    int[] dp = new int[10];
    Arrays.fill(dp, 1);
    for (int step = 2; step <= n; step++) {
        int[] next = new int[10];
        for (int i = 0; i < 10; i++) {
            for (int j : moves[i]) {
                next[j] = (next[j] + dp[i]) % MOD;
            }
        }
        dp = next;
    }
    int res = 0;
    for (int x : dp) res = (res + x) % MOD;
    return res;
}
```

## 十、DP 解题套路

### 1. 5 步法

1. **确定状态**：`dp[i]` / `dp[i][j]` 表示什么
2. **写出转移方程**：手算几个小例子找规律
3. **确定初始条件**：`dp[0]`、`dp[1]`
4. **确定遍历顺序**：自底向上还是自顶向下
5. **举例验证**：代入小例子看是否正确

### 2. 空间优化

- 一维 DP：滚动变量 `prev1`、`prev2`
- 二维 DP：可以降维到一维时，倒序遍历避免污染

### 3. 常见错误

| 错误 | 原因 |
|------|------|
| 转移方程写错 | 仔细分析"最后一步" |
| 初始条件漏掉 | dp[0]、dp[1] 单独处理 |
| 遍历顺序错 | 0/1 背包倒序、完全背包正序 |
| 答案取错位置 | dp[n-1] 还是 dp[n]，看题意 |
| 数组越界 | dp[i+1][j+1] 需要 (m+1)×(n+1) 数组 |
