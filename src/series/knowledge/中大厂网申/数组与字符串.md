## 一、必备基础知识

### 1. 数组特性

- **随机访问**：O(1) 时间访问下标 i
- **插入/删除**：O(n) 时间，需要移动元素
- **数组 vs ArrayList**：
  - 数组定长，性能更好
  - `ArrayList` 自动扩容（×1.5），API 丰富

### 2. 字符串特性

- 不可变对象（`String` 是 `final char[]`）
- 频繁拼接用 `StringBuilder`（非线程安全）或 `StringBuffer`（线程安全）
- 字符串比较用 `equals()`，不用 `==`

### 3. 常用 API

## 二、核心技巧

### 技巧 1：双指针

**适用场景**：
- 有序数组的查找（如两数之和）
- 原地修改数组（如去重、移动零）
- 区间问题（如接雨水）

**两种形式**：
- **对撞指针**：left 从头、right 从尾，向中间靠拢
- **快慢指针**：fast 走得快、slow 走得慢

#### 例题 1：两数之和 II（LeetCode 167）

**题目**：有序数组，找出两数之和等于 target 的下标。

**Java 解法（对撞指针）**：

```java
public int[] twoSum(int[] numbers, int target) {
    int left = 0, right = numbers.length - 1;
    while (left < right) {
        int sum = numbers[left] + numbers[right];
        if (sum == target) return new int[]{left + 1, right + 1};
        else if (sum < target) left++;
        else right--;
    }
    return new int[]{-1, -1};
}
```

#### 例题 2：移动零（LeetCode 283）

**题目**：将所有 0 移到末尾，保持非零元素相对顺序。

**Java 解法（快慢指针）**：

```java
public void moveZeroes(int[] nums) {
    int slow = 0;  // 指向非零元素应该放的位置
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != 0) {
            if (slow != fast) {
                int tmp = nums[slow];
                nums[slow] = nums[fast];
                nums[fast] = tmp;
            }
            slow++;
        }
    }
}
```

#### 例题 3：三数之和（LeetCode 15）

**题目**：找出所有和为 0 的三元组。

**Java 解法（排序+双指针+去重）**：

```java
public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(nums);
    for (int i = 0; i < nums.length - 2; i++) {
        if (nums[i] > 0) break;
        if (i > 0 && nums[i] == nums[i - 1]) continue;  // 去重
        int left = i + 1, right = nums.length - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum == 0) {
                res.add(Arrays.asList(nums[i], nums[left], nums[right]));
                while (left < right && nums[left] == nums[left + 1]) left++;
                while (left < right && nums[right] == nums[right - 1]) right--;
                left++;
                right--;
            } else if (sum < 0) left++;
            else right--;
        }
    }
    return res;
}
```

### 技巧 2：滑动窗口

**适用场景**：
- 子串/子数组求最值
- 满足某条件的连续区间
- 字符串匹配

**核心框架**：

```java
int left = 0, right = 0;
int[] window = new int[128];  // 窗口状态（这里是字符计数）

while (right < s.length()) {
    char c = s.charAt(right);
    window[c]++;
    right++;
    
    // 当窗口需要收缩
    while (/* 收缩条件 */) {
        char d = s.charAt(left);
        window[d]--;
        left++;
    }
    
    // 更新答案
    res = Math.max(res, right - left);
}
```

#### 例题 1：无重复字符的最长子串（LeetCode 3）

```java
public int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> window = new HashMap<>();
    int left = 0, right = 0, res = 0;
    while (right < s.length()) {
        char c = s.charAt(right);
        window.put(c, window.getOrDefault(c, 0) + 1);
        right++;
        while (window.get(c) > 1) {
            char d = s.charAt(left);
            window.put(d, window.get(d) - 1);
            left++;
        }
        res = Math.max(res, right - left);
    }
    return res;
}
```

#### 例题 2：最小覆盖子串（LeetCode 76）

```java
public String minWindow(String s, String t) {
    Map<Character, Integer> need = new HashMap<>();
    Map<Character, Integer> window = new HashMap<>();
    for (char c : t.toCharArray()) need.merge(c, 1, Integer::sum);
    
    int left = 0, right = 0;
    int valid = 0;  // 窗口中满足 need 条件的字符种类数
    int start = 0, len = Integer.MAX_VALUE;
    
    while (right < s.length()) {
        char c = s.charAt(right);
        right++;
        if (need.containsKey(c)) {
            window.merge(c, 1, Integer::sum);
            if (window.get(c).equals(need.get(c))) valid++;
        }
        
        while (valid == need.size()) {
            if (right - left < len) {
                start = left;
                len = right - left;
            }
            char d = s.charAt(left);
            left++;
            if (need.containsKey(d)) {
                if (window.get(d).equals(need.get(d))) valid--;
                window.merge(d, -1, Integer::sum);
            }
        }
    }
    return len == Integer.MAX_VALUE ? "" : s.substring(start, start + len);
}
```

#### 例题 3：找到字符串中所有字母异位词（LeetCode 438）

```java
public List<Integer> findAnagrams(String s, String p) {
    List<Integer> res = new ArrayList<>();
    int[] need = new int[26], window = new int[26];
    for (char c : p.toCharArray()) need[c - 'a']++;
    int left = 0, right = 0, valid = 0;
    while (right < s.length()) {
        int c = s.charAt(right) - 'a';
        if (need[c] > 0) {
            window[c]++;
            if (window[c] == need[c]) valid++;
        }
        right++;
        while (valid == 26) {  // 注意：这里简化为 26，实际应该比 need 字符种类
            if (right - left == p.length()) res.add(left);
            int d = s.charAt(left) - 'a';
            if (need[d] > 0) {
                if (window[d] == need[d]) valid--;
                window[d]--;
            }
            left++;
        }
    }
    return res;
}
```

### 技巧 3：前缀和

**适用场景**：
- 区间求和
- 满足和为 K 的子数组个数
- 矩阵区域和

**核心公式**：
```
prefix[i] = nums[0] + nums[1] + ... + nums[i-1]
nums[i] + ... + nums[j] = prefix[j+1] - prefix[i]
```

#### 例题：和为 K 的子数组（LeetCode 560）

```java
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> map = new HashMap<>();
    map.put(0, 1);  // 前缀和为 0 出现 1 次
    int prefix = 0, count = 0;
    for (int num : nums) {
        prefix += num;
        if (map.containsKey(prefix - k)) {
            count += map.get(prefix - k);
        }
        map.merge(prefix, 1, Integer::sum);
    }
    return count;
}
```

### 技巧 4：位运算

**常用操作**：

```java
// 异或：无进位加法
a ^ a = 0
a ^ 0 = a

// 与：取特定位、判断奇偶
n & 1  // 0 偶 1 奇
n & (n - 1)  // 去掉最低位的 1

// 或：设特定位为 1
n | (1 << k)

// 移位
n >> 1   // 算术右移
n >>> 1  // 逻辑右移
n << 1   // 左移
```

#### 例题：只出现一次的数字（LeetCode 136）

```java
public int singleNumber(int[] nums) {
    int res = 0;
    for (int num : nums) res ^= num;
    return res;
}
```

#### 例题：比特位计数（LeetCode 338）

```java
public int[] countBits(int n) {
    int[] res = new int[n + 1];
    for (int i = 1; i <= n; i++) {
        res[i] = res[i & (i - 1)] + 1;
    }
    return res;
}
```

### 技巧 5：原地哈希

**核心思路**：利用数组下标作为"哈希键"，标记元素出现位置。

#### 例题：缺失的第一个正数（LeetCode 41）

```java
public int firstMissingPositive(int[] nums) {
    int n = nums.length;
    // 1. 把每个 nums[i] 放到下标 nums[i]-1 的位置
    for (int i = 0; i < n; i++) {
        while (nums[i] >= 1 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
            int tmp = nums[nums[i] - 1];
            nums[nums[i] - 1] = nums[i];
            nums[i] = tmp;
        }
    }
    // 2. 找第一个 nums[i] != i+1 的位置
    for (int i = 0; i < n; i++) {
        if (nums[i] != i + 1) return i + 1;
    }
    return n + 1;
}
```

### 技巧 6：单调栈

**适用场景**：
- 下一个更大元素
- 柱状图最大矩形
- 接雨水

**核心思想**：维护一个单调（递增/递减）的栈，遍历时维护单调性。

#### 例题：接雨水（LeetCode 42）

```java
public int trap(int[] height) {
    Deque<Integer> stack = new ArrayDeque<>();  // 存下标，单调递减
    int res = 0;
    for (int i = 0; i < height.length; i++) {
        while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
            int top = stack.pop();
            if (stack.isEmpty()) break;
            int left = stack.peek();
            int w = i - left - 1;
            int h = Math.min(height[i], height[left]) - height[top];
            res += w * h;
        }
        stack.push(i);
    }
    return res;
}
```

#### 例题：每日温度（LeetCode 739）

```java
public int[] dailyTemperatures(int[] temperatures) {
    int n = temperatures.length;
    int[] res = new int[n];
    Deque<Integer> stack = new ArrayDeque<>();
    for (int i = 0; i < n; i++) {
        while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
            int prev = stack.pop();
            res[prev] = i - prev;
        }
        stack.push(i);
    }
    return res;
}
```

#### 例题：柱状图中最大的矩形（LeetCode 84）

```java
public int largestRectangleArea(int[] heights) {
    int n = heights.length;
    int[] left = new int[n], right = new int[n];
    Deque<Integer> stack = new ArrayDeque<>();
    
    // 找左边第一个小于 heights[i] 的位置
    for (int i = 0; i < n; i++) {
        while (!stack.isEmpty() && heights[stack.peek()] >= heights[i]) stack.pop();
        left[i] = stack.isEmpty() ? -1 : stack.peek();
        stack.push(i);
    }
    
    stack.clear();
    // 找右边第一个小于 heights[i] 的位置
    for (int i = n - 1; i >= 0; i--) {
        while (!stack.isEmpty() && heights[stack.peek()] >= heights[i]) stack.pop();
        right[i] = stack.isEmpty() ? n : stack.peek();
        stack.push(i);
    }
    
    int res = 0;
    for (int i = 0; i < n; i++) {
        res = Math.max(res, (right[i] - left[i] - 1) * heights[i]);
    }
    return res;
}
```

## 三、高频面试题

### 1. 反转字符串中的单词（LeetCode 151）

```java
public String reverseWords(String s) {
    // 1. 去除多余空格
    char[] chars = s.toCharArray();
    int slow = 0;
    for (int fast = 0; fast < chars.length; fast++) {
        if (chars[fast] != ' ' || (slow > 0 && chars[slow - 1] != ' ')) {
            chars[slow++] = chars[fast];
        }
    }
    if (slow > 0 && chars[slow - 1] == ' ') slow--;
    
    // 2. 整体反转
    reverse(chars, 0, slow - 1);
    
    // 3. 反转每个单词
    int start = 0;
    for (int i = 0; i <= slow; i++) {
        if (i == slow || chars[i] == ' ') {
            reverse(chars, start, i - 1);
            start = i + 1;
        }
    }
    return new String(chars, 0, slow);
}

private void reverse(char[] chars, int left, int right) {
    while (left < right) {
        char tmp = chars[left];
        chars[left] = chars[right];
        chars[right] = tmp;
        left++;
        right--;
    }
}
```

### 2. 字符串解码（LeetCode 394）

```java
public String decodeString(String s) {
    Deque<Integer> countStack = new ArrayDeque<>();
    Deque<String> resultStack = new ArrayDeque<>();
    StringBuilder res = new StringBuilder();
    int k = 0;
    for (char c : s.toCharArray()) {
        if (Character.isDigit(c)) {
            k = k * 10 + (c - '0');
        } else if (c == '[') {
            countStack.push(k);
            resultStack.push(res.toString());
            k = 0;
            res = new StringBuilder();
        } else if (c == ']') {
            StringBuilder tmp = new StringBuilder();
            int cnt = countStack.pop();
            for (int i = 0; i < cnt; i++) tmp.append(res);
            res = new StringBuilder(resultStack.pop() + tmp);
        } else {
            res.append(c);
        }
    }
    return res.toString();
}
```

### 3. 乘积最大子数组（LeetCode 152）

```java
public int maxProduct(int[] nums) {
    int n = nums.length;
    int max = nums[0], min = nums[0], res = nums[0];
    for (int i = 1; i < n; i++) {
        if (nums[i] < 0) {
            int tmp = max;
            max = min;
            min = tmp;
        }
        max = Math.max(nums[i], max * nums[i]);
        min = Math.min(nums[i], min * nums[i]);
        res = Math.max(res, max);
    }
    return res;
}
```

### 4. 长度最小的子数组（LeetCode 209）

```java
public int minSubArrayLen(int target, int[] nums) {
    int left = 0, sum = 0, res = Integer.MAX_VALUE;
    for (int right = 0; right < nums.length; right++) {
        sum += nums[right];
        while (sum >= target) {
            res = Math.min(res, right - left + 1);
            sum -= nums[left++];
        }
    }
    return res == Integer.MAX_VALUE ? 0 : res;
}
```

### 5. 轮转数组（LeetCode 189）

```java
public void rotate(int[] nums, int k) {
    k %= nums.length;
    reverse(nums, 0, nums.length - 1);
    reverse(nums, 0, k - 1);
    reverse(nums, k, nums.length - 1);
}

private void reverse(int[] nums, int left, int right) {
    while (left < right) {
        int tmp = nums[left];
        nums[left] = nums[right];
        nums[right] = tmp;
        left++;
        right--;
    }
}
```

## 五、避坑指南

| 陷阱 | 应对 |
|------|------|
| 整数溢出 | 阶乘、累加用 `long` |
| 数组越界 | 访问前判 `i < n && i >= 0` |
| 字符串拼接 | 循环中用 `StringBuilder` |
| 数组长度 | 区分 `arr.length` 和 `list.size()` |
| 字符运算 | `s.charAt(i) - 'a'` 才是 0-25 |
| 空指针 | 输入可能为 `null`，加判断 |
| 浮点数比较 | 不要 `== 0`，用 `Math.abs(x) < 1e-9` |
| 边界值 | n=0、n=1、全相同、单元素 |
