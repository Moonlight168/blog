## 一、哈希表基础

### 1. Java 哈希表 API

```java
// HashMap
Map<K, V> map = new HashMap<>();
map.put(key, value);
map.get(key);
map.getOrDefault(key, defaultVal);
map.containsKey(key);
map.merge(key, val, Integer::sum);   // 不存在则 put，存在则合并
map.remove(key);
map.size();
map.isEmpty();
map.keySet();     // 所有 key
map.values();     // 所有 value
map.entrySet();   // 所有 entry

// HashSet
Set<T> set = new HashSet<>();
set.add(t);
set.contains(t);
set.remove(t);

// LinkedHashMap：保留插入顺序
Map<K, V> lhm = new LinkedHashMap<>();

// TreeMap：按键排序
Map<K, V> tm = new TreeMap<>();
```

### 2. 哈希表原理

- **数组 + 链表 / 红黑树**（Java 8+ 链表长度 > 8 转红黑树）
- **put 操作**：计算 hash → 定位桶 → 处理冲突
- **hashCode 与 equals**：键对象必须正确重写
- **装载因子**：默认 0.75，超过会扩容

### 3. 自定义 HashMap 键

```java
class Pair {
    int a, b;
    Pair(int a, int b) { this.a = a; this.b = b; }
    
    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (!(o instanceof Pair)) return false;
        Pair p = (Pair) o;
        return a == p.a && b == p.b;
    }
    
    @Override
    public int hashCode() {
        return Objects.hash(a, b);
    }
}
```

```java
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (map.containsKey(complement)) {
            return new int[]{map.get(complement), i};
        }
        map.put(nums[i], i);
    }
    return new int[]{-1, -1};
}
```

### 3. 最长连续序列（LeetCode 128）

```java
public int longestConsecutive(int[] nums) {
    Set<Integer> set = new HashSet<>();
    for (int num : nums) set.add(num);
    int res = 0;
    for (int num : set) {
        if (!set.contains(num - 1)) {  // num 是序列起点
            int cur = num, len = 1;
            while (set.contains(cur + 1)) {
                cur++;
                len++;
            }
            res = Math.max(res, len);
        }
    }
    return res;
}
```

### 4. 和为 K 的子数组（LeetCode 560）

```java
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> map = new HashMap<>();
    map.put(0, 1);
    int prefix = 0, count = 0;
    for (int num : nums) {
        prefix += num;
        count += map.getOrDefault(prefix - k, 0);
        map.merge(prefix, 1, Integer::sum);
    }
    return count;
}
```

### 5. 前 K 个高频元素（LeetCode 347）

```java
public int[] topKFrequent(int[] nums, int k) {
    Map<Integer, Integer> count = new HashMap<>();
    for (int num : nums) count.merge(num, 1, Integer::sum);
    
    // 桶排序
    List<Integer>[] buckets = new List[nums.length + 1];
    for (Map.Entry<Integer, Integer> e : count.entrySet()) {
        int freq = e.getValue();
        if (buckets[freq] == null) buckets[freq] = new ArrayList<>();
        buckets[freq].add(e.getKey());
    }
    
    int[] res = new int[k];
    int idx = 0;
    for (int i = buckets.length - 1; i >= 0 && idx < k; i--) {
        if (buckets[i] != null) {
            for (int num : buckets[i]) {
                res[idx++] = num;
                if (idx == k) break;
            }
        }
    }
    return res;
}
```

## 三、设计题——大厂最爱

### 1. LRU 缓存（LeetCode 146）— 必考

**需求**：
- `get(key)`：O(1) 时间
- `put(key, value)`：O(1) 时间
- 容量满时淘汰最久未使用

**核心数据结构**：哈希表 + 双向链表

```java
class LRUCache {
    static class DLinkedNode {
        int key, value;
        DLinkedNode prev, next;
        DLinkedNode() {}
        DLinkedNode(int k, int v) { key = k; value = v; }
    }
    
    private Map<Integer, DLinkedNode> cache = new HashMap<>();
    private int capacity;
    private DLinkedNode head, tail;  // 哨兵节点
    
    public LRUCache(int capacity) {
        this.capacity = capacity;
        head = new DLinkedNode();
        tail = new DLinkedNode();
        head.next = tail;
        tail.prev = head;
    }
    
    public int get(int key) {
        DLinkedNode node = cache.get(key);
        if (node == null) return -1;
        moveToHead(node);
        return node.value;
    }
    
    public void put(int key, int value) {
        DLinkedNode node = cache.get(key);
        if (node != null) {
            node.value = value;
            moveToHead(node);
        } else {
            DLinkedNode newNode = new DLinkedNode(key, value);
            cache.put(key, newNode);
            addToHead(newNode);
            if (cache.size() > capacity) {
                DLinkedNode removed = removeTail();
                cache.remove(removed.key);
            }
        }
    }
    
    private void addToHead(DLinkedNode node) {
        node.prev = head;
        node.next = head.next;
        head.next.prev = node;
        head.next = node;
    }
    
    private void removeNode(DLinkedNode node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }
    
    private void moveToHead(DLinkedNode node) {
        removeNode(node);
        addToHead(node);
    }
    
    private DLinkedNode removeTail() {
        DLinkedNode node = tail.prev;
        removeNode(node);
        return node;
    }
}
```

**复杂度分析**：
- 哈希表 O(1) 查找
- 双向链表 O(1) 插入/删除/移动
- 整体 O(1) 时间复杂度

### 2. LFU 缓存（LeetCode 460）— Hard

**需求**：淘汰**最不经常使用**（频次最低）的节点，频次相同时淘汰最久未使用。

**核心**：双向链表 + 频率映射

```java
class LFUCache {
    Map<Integer, DLinkedNode> nodeMap = new HashMap<>();  // key -> 节点
    Map<Integer, DLinkedList> freqMap = new HashMap<>();  // freq -> 双向链表
    int capacity, size, minFreq;
    
    public LFUCache(int capacity) {
        this.capacity = capacity;
    }
    
    public int get(int key) {
        DLinkedNode node = nodeMap.get(key);
        if (node == null) return -1;
        increaseFreq(node);
        return node.value;
    }
    
    public void put(int key, int value) {
        if (capacity == 0) return;
        DLinkedNode node = nodeMap.get(key);
        if (node != null) {
            node.value = value;
            increaseFreq(node);
        } else {
            if (size == capacity) {
                DLinkedList minList = freqMap.get(minFreq);
                DLinkedNode removed = minList.removeTail();
                nodeMap.remove(removed.key);
                size--;
            }
            DLinkedNode newNode = new DLinkedNode(key, value);
            nodeMap.put(key, newNode);
            freqMap.computeIfAbsent(1, k -> new DLinkedList()).addToHead(newNode);
            size++;
            minFreq = 1;
        }
    }
    
    private void increaseFreq(DLinkedNode node) {
        int freq = node.freq;
        DLinkedList list = freqMap.get(freq);
        list.removeNode(node);
        
        if (freq == minFreq && list.isEmpty()) minFreq++;
        
        node.freq++;
        freqMap.computeIfAbsent(node.freq, k -> new DLinkedList()).addToHead(node);
    }
}

class DLinkedNode {
    int key, value, freq;
    DLinkedNode prev, next;
    DLinkedNode(int k, int v) { key = k; value = v; freq = 1; }
}

class DLinkedList {
    DLinkedNode head, tail;
    DLinkedList() {
        head = new DLinkedNode(0, 0);
        tail = new DLinkedNode(0, 0);
        head.next = tail;
        tail.prev = head;
    }
    
    void addToHead(DLinkedNode node) {
        node.prev = head;
        node.next = head.next;
        head.next.prev = node;
        head.next = node;
    }
    
    void removeNode(DLinkedNode node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }
    
    DLinkedNode removeTail() {
        DLinkedNode node = tail.prev;
        removeNode(node);
        return node;
    }
    
    boolean isEmpty() {
        return head.next == tail;
    }
}
```

### 3. O(1) 时间插入、删除、获取随机元素（LeetCode 380）

**核心**：哈希表 + 数组（哈希表存下标）

```java
class RandomizedSet {
    private List<Integer> list = new ArrayList<>();
    private Map<Integer, Integer> map = new HashMap<>();
    private Random random = new Random();
    
    public boolean insert(int val) {
        if (map.containsKey(val)) return false;
        map.put(val, list.size());
        list.add(val);
        return true;
    }
    
    public boolean remove(int val) {
        if (!map.containsKey(val)) return false;
        int idx = map.get(val);
        int last = list.get(list.size() - 1);
        list.set(idx, last);
        map.put(last, idx);
        list.remove(list.size() - 1);
        map.remove(val);
        return true;
    }
    
    public int getRandom() {
        return list.get(random.nextInt(list.size()));
    }
}
```

### 4. 黑名单中的随机数（LeetCode 710）— Hard

```java
class Solution {
    int n, sz;
    Map<Integer, Integer> map = new HashMap<>();
    
    public Solution(int n, int[] blacklist) {
        this.n = n;
        this.sz = n - blacklist.length;
        Set<Integer> black = new HashSet<>();
        for (int b : blacklist) {
            if (b >= sz) black.add(b);
        }
        int last = n - 1;
        for (int b : blacklist) {
            if (b < sz) {
                while (black.contains(last)) last--;
                map.put(b, last);
                last--;
            }
        }
    }
    
    public int pick() {
        int idx = new Random().nextInt(sz);
        return map.getOrDefault(idx, idx);
    }
}
```

### 5. 时间戳键值存储（LeetCode 981）— Medium

```java
class TimeMap {
    Map<String, List<Pair<Integer, String>>> map = new HashMap<>();
    
    public void set(String key, String value, int timestamp) {
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(new Pair<>(timestamp, value));
    }
    
    public String get(String key, int timestamp) {
        List<Pair<Integer, String>> list = map.get(key);
        if (list == null) return "";
        int left = 0, right = list.size() - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (list.get(mid).getKey() <= timestamp) left = mid + 1;
            else right = mid - 1;
        }
        return right >= 0 ? list.get(right).getValue() : "";
    }
}
```

### 6. 设计推特（LeetCode 355）— Medium

```java
class Twitter {
    private Map<Integer, List<int[]>> tweets = new HashMap<>();
    private Map<Integer, Set<Integer>> following = new HashMap<>();
    private int time = 0;
    
    public void postTweet(int userId, int tweetId) {
        tweets.computeIfAbsent(userId, k -> new ArrayList<>()).add(new int[]{time++, tweetId});
    }
    
    public List<Integer> getNewsFeed(int userId) {
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> b[0] - a[0]);
        Set<Integer> users = new HashSet<>(following.getOrDefault(userId, new HashSet<>()));
        users.add(userId);
        
        for (int u : users) {
            List<int[]> userTweets = tweets.get(u);
            if (userTweets != null) {
                for (int[] tweet : userTweets) {
                    pq.offer(tweet);
                }
            }
        }
        
        List<Integer> res = new ArrayList<>();
        while (!pq.isEmpty() && res.size() < 10) {
            res.add(pq.poll()[1]);
        }
        return res;
    }
    
    public void follow(int followerId, int followeeId) {
        following.computeIfAbsent(followerId, k -> new HashSet<>()).add(followeeId);
    }
    
    public void unfollow(int followerId, int followeeId) {
        following.getOrDefault(followerId, new HashSet<>()).remove(followeeId);
    }
}
```

## 四、字符串哈希（滚动哈希）

### Rabin-Karp 字符串匹配

```java
public int strStr(String haystack, String needle) {
    int m = haystack.length(), n = needle.length();
    if (n == 0) return 0;
    long base = 256, mod = (long) 1e9 + 7;
    long h = 1, hashNeedle = 0, hashHay = 0;
    for (int i = 0; i < n - 1; i++) h = (h * base) % mod;
    for (int i = 0; i < n; i++) {
        hashNeedle = (hashNeedle * base + needle.charAt(i)) % mod;
        hashHay = (hashHay * base + haystack.charAt(i)) % mod;
    }
    for (int i = 0; i <= m - n; i++) {
        if (hashHay == hashNeedle) {
            if (haystack.substring(i, i + n).equals(needle)) return i;
        }
        if (i < m - n) {
            hashHay = ((hashHay - haystack.charAt(i) * h) * base + haystack.charAt(i + n)) % mod;
            if (hashHay < 0) hashHay += mod;
        }
    }
    return -1;
}
```

## 五、哈希 + 双向链表实战模板

### 设计浏览器历史（LeetCode 1472）

```java
class BrowserHistory {
    static class Node {
        String url;
        Node prev, next;
        Node(String url) { this.url = url; }
    }
    
    private Node cur;
    
    public BrowserHistory(String homepage) {
        cur = new Node(homepage);
    }
    
    public void visit(String url) {
        Node newNode = new Node(url);
        newNode.prev = cur;
        cur.next = null;
        cur = newNode;
    }
    
    public String back(int steps) {
        while (steps > 0 && cur.prev != null) {
            cur = cur.prev;
            steps--;
        }
        return cur.url;
    }
    
    public String forward(int steps) {
        while (steps > 0 && cur.next != null) {
            cur = cur.next;
            steps--;
        }
        return cur.url;
    }
}
```

## 八、避坑指南

| 陷阱 | 应对 |
|------|------|
| HashMap 线程不安全 | 多线程用 `ConcurrentHashMap` |
| 自定义键未重写 hashCode/equals | 必须重写，否则 hash 冲突 |
| 哈希表空间 | 默认 16 桶，装载因子 0.75 |
| 链表转红黑树 | Java 8 桶内 > 8 元素时 |
| 删除时要先 remove 再 put | 否则下次可能拿到旧值 |
| computeIfAbsent 中修改 map | 可能 ConcurrentModificationException |
| null 键值 | HashMap 允许，ConcurrentHashMap 不允许 |
