# FlowMind 架构设计

## 一、总体架构

FlowMind 是基于 **RuoYi-Cloud + Flowable + LangGraph** 构建的智能工作流管理系统，由三大子项目协同工作：

```
┌────────────────────────────────────────────────────────────────────────┐
│                  前端 (flowmind-ui)                                    │
│         Vue 3 + Element Plus + BPMN-JS + v-form-designer              │
└──────────────┬─────────────────────────────────┬──────────────────────┘
               │ HTTP                             │ SSE/WebSocket
               ▼                                 ▼
┌──────────────────────────┐       ┌────────────────────────────────────┐
│  后端 (flowmind-cloud)   │       │  AI 服务 (flowmind-ai-flow)        │
│  Spring Cloud + Flowable │◄──────┤  FastAPI + LangGraph + ReAct      │
└──────────────┬───────────┘       └────────────────────────────────────┘
               │
               ▼
┌────────────────────────────────────────────────────────────────────────┐
│        基础设施：MySQL / Redis / Nacos / MinIO / Sentinel             │
└────────────────────────────────────────────────────────────────────────┘
```

> **注意**：关于 FlowMind 的详细模块设计和功能实现，请参考 [模块设计文档](模块设计.md)

## 二、系统架构层次

### 2.1 微服务架构层次

FlowMind 采用分层微服务架构，主要包括以下层次：

- **网关层**：Spring Cloud Gateway 统一入口
- **认证层**：Spring Security + JWT 安全认证
- **业务层**：各业务微服务模块
- **AI 服务层**：FastAPI + LangGraph 智能设计与 ReAct Agent
- **数据层**：MySQL + Redis 数据存储
- **工作流层**：Flowable 工作流引擎

### 2.2 服务间通信架构

- **同步通信**：OpenFeign + LoadBalancer
- **异步通信**：Spring Task + WebSocket
- **分布式事务**：Seata 事务管理
- **AI 流式通信**：SSE（Server-Sent Events）

## 三、AI 智能设计架构

### 3.1 核心层级

```
api/ → agents/ → graph/ → adapters/ → infra/
```

- **adapters/**：LLM 适配器（OpenAI 兼容接口），后端 API 适配器
- **agents/**：业务 Agent（category / flow / form design）
- **graph/**：LangGraph 工作流，intent_node 识别后路由到子工作流
- **domain/dto/**：数据传输对象（ApprovalFlowDTO 等）

### 3.2 设计模式

| 模式 | 应用位置 | 说明 |
| --- | --- | --- |
| 适配器模式 | LLM 适配器 | 屏蔽不同 LLM 提供商接口差异 |
| 工厂模式 | ModelFactory | 统一创建 LLM 实例 |
| 策略模式 | routing/ | 基于意图路由到子工作流 |
| 模板方法 | BaseAgent | 统一的 Agent 抽象基类 |

### 3.3 ReAct Agent 架构

```
用户输入 → Reasoning(意图分析) → Acting(工具调用) → Observation(结果观察)
                                  ↑                              │
                                  └────────── 循环/追问 ─────────┘
                                            │
                                            ▼
                                      最终结果输出
```

- **智能推理**：AI 分析用户意图，规划执行步骤
- **工具调用**：动态调用 BPMN 设计、表单生成等工具
- **追问机制**：主动询问缺失信息，确保设计完整
- **结果验证**：自动验证生成结果的正确性

### 3.4 全局 AI 助手

- 悬浮式 UI 入口
- 对话历史持久化（Redis）
- 一键跳转到对应设计页面

## 四、性能优化架构

### 4.1 性能优化策略

| 优化方向 | 具体措施 | 预期效果 |
| --- | --- | --- |
| 数据库 | 索引优化、查询优化 | 提升查询性能 |
| 缓存 | Redis 缓存热点数据 | 减少数据库压力 |
| 异步处理 | 异步处理非关键业务流程 | 提升响应速度 |
| 限流 | 接口限流防止系统过载 | 保障系统稳定 |
| AI 流式 | SSE 流式输出 | 降低首字延迟 |

### 4.2 监控与告警

- **应用监控**：Spring Boot Actuator + Micrometer
- **链路追踪**：SkyWalking 分布式追踪
- **日志监控**：ELK 日志分析平台
- **告警机制**：Prometheus + Alertmanager

---

## 五、安全架构

### 5.1 认证授权架构

FlowMind 采用多层次安全架构，确保系统安全性：

- **用户认证**：Spring Security + JWT Token
- **权限控制**：基于角色的访问控制（RBAC）
- **接口安全**：接口签名验证 + 防重放攻击
- **数据安全**：敏感数据加密存储

### 5.2 数据安全

- **数据传输**：HTTPS 加密传输
- **数据存储**：敏感字段加密存储
- **数据脱敏**：日志中敏感信息脱敏处理
- **数据备份**：定期数据备份与恢复机制
