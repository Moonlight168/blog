# Java 面试答题记录

## HashMap 在 JDK 1.8 做了什么优化？

- **2026-07-20**：不知道

## 堆内存分几块？对象刚创建放哪？

- **2026-07-20**：分为老年代和年轻代，放年轻代

## 线程池任务提交流程？

- **2026-07-20**：获取当前可用线程池，请求线程，拿锁失败，返回当前无分配的线程

## `==` 和 `equals` 的区别？Integer 用哪个比？

- **2026-07-20**：== 比对象值，equals比对象地址，用 ==

## JVM Minor GC 和 Full GC 区别？什么时候触发 Full GC？

- **2026-07-21**：mior是清理老年代的，full gc是清除全部，好像是比例超过多少就触发

## 线程池核心参数和任务提交流程？

- **2026-07-21**：请求到先请求核心线程，然后请求最大线程数，如果系统最大可用现场数也大于，就拒绝

## volatile 保证什么？和 synchronized 的区别？

- **2026-07-21**：保证可见性不保证原子性，synchronized 保证


## HashMap 底层数据结构？什么时候转红黑树，为什么是 8？

- **2026-07-21**：底层好像是链表+红黑树，链表长度达到8就转红黑树，这个转红黑树才有意义，至少三层

## 线程池核心参数有哪些？核心线程和最大线程区别？

- **2026-07-21**：核心线程数，最大线程数，拒绝策略。核心线程用完还在

## `==` 和 `equals` 区别？Integer 缓存范围是？

- **2026-07-21**：== 比地址 equals比值，true,false,interger超过128 就比地址了

## synchronized 锁升级过程是怎样的？

- **2026-07-23**：从轻量锁到重量锁（漏了偏向锁）

## JVM 运行时内存区域是怎么划分的？

- **2026-07-23**：Eden 代、老年代、存活区（只说了堆内分代，漏了线程私有的虚拟机栈、程序计数器、本地方法栈）

## JDK 8 以后 JVM 内存区域有什么变化？

- **2026-07-23**：方法区改成元空间、用本地内存是核心区别

## ThreadLocal 是什么？有哪些使用场景？内存泄漏是怎么造成的？

- **2026-07-23**：
  - 是什么：线程类（概念错误）
  - 使用场景：多线程使用吧（笼统，未答出具体场景）
  - 内存泄漏：泄露可能爆了吧（概念模糊；追问后发现理解了 key 回收、value 无人能访问的道理）
