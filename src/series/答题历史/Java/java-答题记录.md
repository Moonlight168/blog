## `git merge` vs `git rebase`？

- **2026-07-20**：merge会有合并信息，rebase是变基到对应要合并的分支的head，然后可以保持提交历史的线性和整洁。开发一般用merge

## 线程池任务提交流程？

- **2026-07-20**：获取当前可用线程池，请求线程，拿锁失败，返回当前无分配的线程

## `==` 和 `equals` 的区别？Integer 用哪个比？

- **2026-07-20**：== 比对象值，equals比对象地址，用 ==

## Docker 多阶段构建解决什么？

- **2026-07-20**：保证构建的阶段性成功？避免重复构建？
